# 独立角色训练头：单一训练职责假设

登记日期：2026-10-06。依据完整§857–871结果，当前状态为源码准备，尚无真实初始化、M0或正式指标。

## 问题与主假设

在匹配作者配方与全局职责分离下，原semantic角色对独立global的净增量仍薄。容量、视觉anchor候选重建、槽位消息分配及纯mask均未达到各自推进条件。源SIM有独立训练头，但与当前角色还有聚合、容量、目标及部署维度差异，不能把其车辆增益唯一归因于独立头。

本轮只检验：当前角色必须沿用仅由global训练的头，是否限制了修正适应身份目标的能力。新模型保持原semantic证据、raw特征、作者损失与1536维推理，让fused身份头独立学习。不是追加新的局部分类辅助loss，也不以头的存在计作论文创新。

## 比较与归因边界

新三端分别与封存的raw-semantic、独立global-only比较，不重新训练旧控制。新global头只接受原L_g；角色输入及训练g仍stop-gradient，独立fused头与roles/readout/gain接受原L_f。仍为L_g+L_f，不改CE/Triplet权重、raw输入或车辆分头，不改gain、margin、学习率、seed或采样。

新增头从每个原global BN/分类头deepcopy，无新随机抽样。201新增一套1536维BN/分类头，车辆新增三套512维头；新增可训练参数为1536×(训练身份数+1)，张量数201为2、车辆为6。BN bias沿用作者冻结行为，各自运行统计独立。额外头只训练使用，不改变部署编码器或1536维L2向量。

反对解释：提升可能来自独立训练头的额外自由度，而非新增证据来源或原创模块。本轮不声称严格同可训练容量，不证明头限制是唯一根因，也不重复将“分支可分类”视为互补成功。旧局部ID、detach、joint-L2失败保持封存。

RGBNT201 semantic → MSVR310 semantic → RGBNT100 semantic。各端fresh公开CLIP、新camera及原头，seed42、完整50轮，B/K依次64/8、64/4、128/16。作者Adam分组、增强、日程、原AMP/FP32边界和两卡分段不变。旧RAW九控制/187依赖与当前374科学源码保持SHA。

每端prepare → 完整实际batch初值对照 → 8更新M0 → fresh50 → 首次strict。新共同state、原raw/global/L2及global/fused logits初值必须与封存raw-semantic初始化一致；独立头初值拷贝一致。CPU先验证L_g不更新角色/新头、L_f不更新global/原头，参数与buffer所有权明确。

真实M0沿用全部可训练张量累计非零有限梯度、visual/camera变化、optimizer恰好覆盖一次和原重载容差。另记录新增2/6张量累计活动及变化、global和role各BN计数8。失败不改门、不重试同失败、不改变batch或延长M0。

主要比较新模型−raw-semantic，推进线仍为ΔmAP≥0.5个百分点且R1不下降；新模型−独立global同条件单列，不能只相对自身global算成功。每端保留同一份mAP-best，全部CMC跟随，不拼epoch。使用全部query/gallery与原camera/时间过滤，无测试时更新。

完整三端结束后一次CPU全query报告，共六配对；保存首位修复/新增错误、query与身份AP分布、完整150轮loss/指标轨迹、参数量、实际训练/评价时间及SHA。训练batch顺序需与两个旧控制逐字节相同。若结果负，停止该头适配解释，不再叠加N1/N2/N3救分。若结果正，仍需完整流程多种子及进一步必要性对照才能形成机制主张。
