## 当前实际在比较的网络

车辆比较使用原V8平行角色结构，没有继承V23模态MLP或V24原型：
冻结完整Signal/CLIP；在block8之后分成CNN、Transformer、Mamba，
三路径分别运行共享冻结tail9/10/11并插入相应角色算子。
CNN读取四个水平分区的Patch残差，Transformer读取CLS残差，
Mamba读取空间与位置级三模态扫描后的Patch均值残差。
三条路径全部执行；共享权重没有把三次尾部计算变成一次。

每个纯角色残差为1536D，三角色银行4608D；与3072D Signal拼成7680D fused。
日志中的cnn/transformer/mamba各为4608D“Signal＋该角色残差”，不是纯残差分数。
令r_e表示纯角色残差，则同一模型、同一图像对有：

s_fused = 0.5 s_Signal + (s_r_CNN + s_r_Transformer + s_r_Mamba) / 6
        = (s_full_CNN + s_full_Transformer + s_full_Mamba) / 3。

这是相似度关系，不能据此平均三支mAP。
原Signal前缀保留提供独立baseline输出，不保证融合后的排序不下降。
已有七组ID/Triplet监督，补“专家独立监督”不是新的修复。
实际FLOPs和独立推理延迟尚未测量，不能只用可训练参数量宣称低计算成本。

所有query的camera标签都在各自source出现，MSVR310仅7条query的scene未见。
当前主要检验已有环境标签下的新身份检索；不能把普遍失效直接归为全新camera/scene标签。
但已见标签不等于光照、遮挡、视角或背景分布相同，也没有排除环境捷径。

RGBNT201全部query的同camera负候选比例均值为45.3665%，不能因四个camera就取25%作机会基线。
这仍是候选池构成，不是最近错误来自同camera的概率；
不能直接拿全体均值与V17新增错误子集9/14做显著性或因果比较。

RGBNT100没有仅作图库的身份，所有身份都贡献合法query；其他身份干扰仍完整保留，
每query平均约2727条，合法正例为50–175条。
这与RGBNT201的4–20条及MSVR310的1–29条正例差别很大，
不同数据集的内部mAP不能作为相同难度的分数直接相减。

## 原推荐路线中，哪些已经做过，哪些仍未被证明

- **模态专属语义适配：** V23固定方案已完成且未通过。不得继续写成待完成实验，也不调宽度/层数重跑。
- **环境内身份区分和弱视图原型监督强视图：** V24已经做了具体配对实现并未通过。
  它使用每折全部94个source身份的108个真实身份/相机成员，弱视图更新EMA，强视图接受全局及同相机身份约束。
  它没有改变PK采样，也不是样本级FIFO队列或Smooth-AP。
- **真实跨摄像头正关系的物理采样覆盖：** 原RGBNT201重放约8.0708%的事实保持。
  V24不能作为改变采样覆盖有效或无效的证据。任何新合同都应保留全部真实身份和跨相机同ID正关系。
- **样本级困难负例记忆：** 与均值原型不同，尚不能以V24替代其试验。
  但全部clean source的全局最难正/负诊断在终点仅约1.4%–1.9%记录违反固定0.3单位距离间隔，
  所以“直接扩大同一批clean source负例池必然得到充足新监督”缺乏支持。
  这不覆盖真实强增强分布，也不证明XBM普遍无效。
- **去风格再恢复身份信息、共享/私有表示、串行异构聚合：** 仍是研究方向。
  论文机制和当前Token/读出方式不等价，不在运行中的车辆比较里加入这些组件。

上述区分来自实际代码和配对终态，不给IICI、SNR、XBM等整条研究方向作普遍成败判决。
既有raw四分区只读诊断也比当前投影头更差，不能把“直接去掉投影头”当作已证明的修复。

## 接续动作与报告边界

先结束RGBNT100固定三折20epoch比较。全部终态后，统一核验三份权重、十五组特征/距离、
43375条query-output排名、全部实际更新、50身份贡献和五项原登记条件。
不选部分fold，不改变门，不根据中间检索结果调参。
若未通过，封存该配置；若通过，也仅支持该内部单seed协议，后续主训练应另行登记。

之后结合三个数据集结果确定一个明确的新主假设。
原综述推荐的环境身份原型已经有V24负证据，不应继续把它当成未经检验的首选修复；
样本记忆或新采样要说明它相对于V24增加了什么可验证监督。
结构重构需要重新定义角色、输出和对照，不能保留已不成立的旧叙事。

RGBNT201可部署固定dev仍是V8 Phase-B 58.4050/59.3939，
相对同协议Signal的mAP提高0.3941pp，距离65门仍差6.5950pp。
最近这些Q1与车辆内部成绩都不能取代官方测试；目前没有新的官方SOTA结果。
车辆完整比较尚不匹配Signal与新增角色的总训练计算，容量、角色、效率及多种子消融
继续按用户要求放在主结果成功之后。当前只使用seed42。

RGBNT100 B0、M0和正在进行的比较尚无独立审计终态；服务额度限制与执行者全量核验分别记录。
已有V23、V24和MSVR310独立审计保留同模型家族及远端二进制回执范围，不能作为跨家族认证。
