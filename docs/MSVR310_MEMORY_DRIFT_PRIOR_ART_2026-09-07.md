# 历史记忆坐标修正：已核查的近邻方法与本项目边界

2026-09-07读取原论文，不据二手转载声称新颖性或录用状态。

XBM缓存此前batch的实例embedding，利用训练后特征慢变化近似当前表示，扩大度量学习候选集合。这是已有方法；本项目实例记忆V1不称原创。[Cross-Batch Memory，CVPR 2020](https://arxiv.org/html/1912.06798)

《Adaptive Cross Batch Normalization for Metric Learning》arXiv:2303.17127v1，2023-03-30，作者Ajanthan、Ma、van den Hengel、Gould。XBN将历史记忆的逐维均值/标准差匹配到当前batch；AXBN用Kalman滤波估计随训练变化的数据统计，再适配记忆。论文已经把表征漂移作为记忆监督误差处理；不是本项目首次发现或首次修正。此处核实预印本，不声称已在TMLR录用。[原文§2.1、§3](https://arxiv.org/html/2303.17127v1)

对本项目的推断：B64/K8下批次身份组成会影响经验统计；对整个7680D做矩匹配，还可能改变实际冻结且不漂移的Signal前缀。是否发生、是否有害均须实测，这不是论文对TriFusion的结论。XBN修正历史表示坐标，V27 MixStyle扰动来源特征统计，两者处理对象不同。

当前完整来源测量通过复用冻结字段、重跑当前角色，直接比较同一历史视图的新旧编码与实际参数梯度。这是诊断与计算复用工程，不单独包装成算法创新。运行中不加入XBN/AXBN、不改原更新loss；先完成固定六端测量。若后续证据支持开发缓存适配，在允许机制比较的阶段需正面对照已有矩匹配/普通XBM，不能只与无记忆模型比较后宣称独创。
