# 历史候选梯度为何可能抵消当前侧梯度

这是一项数学解释，用于限定当前固定状态诊断的结论，不是新实验、论文创新主张或MSVR310失败的已证实原因。完整来源诊断尚未结束，当前没有登记新的历史反传训练。

## 同一个目标的两个导数项

对当前样本表示U(θ)和历史视图在当前参数下的表示V(θ)，同一个损失L的完整参数梯度为：

    g = J_Uᵀ ∂L/∂U + J_Vᵀ ∂L/∂V = g_U + g_V

历史特征停止梯度时只保留g_U。这不是两个独立任务分别提出的优化目标。g_U与g_V的余弦为负，可能只是同一个函数对两个输入的导数存在抵消，不能仅凭负余弦称为有害任务冲突，也不能据此引入PCGrad。

当前实现的当前batch样本既作anchor也作同批候选，相关梯度已经包含在g_U中。尚被停止梯度的是历史候选；补上g_V不增加历史anchor，不自动得到一个对称大batch目标。

## 一个保持距离不变的理论例子

取单位角色槽位x、y，对所有样本的该槽位施加相同正交旋转R(t)=exp(tA)，其中Aᵀ=−A。其他槽位与Signal前缀保持固定。由于：

    ||R(t)x − R(t)y||² = ||x − y||²

当前等权拼接表示的所有样本对距离不变。这个变换不会改善任何身份排序；它只改变该槽位的坐标方向。

在t=0，把历史y当成常量时，平方距离对t的当前侧导数为：

    D_U = 2(x−y)ᵀ A x

允许历史候选一侧也随同一旋转变化，则新增：

    D_V = −2(x−y)ᵀ A y

相加得到：

    D_U + D_V = 2(x−y)ᵀ A(x−y) = 0

最后一步来自反对称矩阵的二次型恒为零。若D_U非零，两项就必须相互抵消。此处用平方距离使零距离处也无除法问题；对于正距离，欧氏距离的导数只是共同乘以1/(2d)，抵消仍成立。所有距离在整个旋转路径都恒定，因此由这些距离构造的最难正负选择和hinge标量也恒定。

槽位在fused中的1/√18系数只增加一个共同常数因子；不影响结论。这里只说明纯度量损失的距离不变方向，不声称固定分类头的其他ID损失也具有相同不变性。

## 对项目证据的正确用法

这个例子说明：部分梯度很大、历史侧与当前侧负相关，并不足以判定历史侧有害，也不足以判定额外梯度能改善检索。它可能消除对共同坐标变化的无效驱动，也可能改变真正的身份间隔；实际网络中的两类成分需要证据区分。

当前诊断没有识别或拟合这样的旋转A，也没有证明历史漂移主要由共同旋转构成。不能将上述例子写成MSVR310的实测机制，不能把全部历史梯度称为“去旋转梯度”。真实模型的更新还包含其他13项损失、AdamW状态、有限步长及参数化限制，梯度夹角不等于最终参数更新或新身份mAP。

因此，完整来源分析应首先报告贡献覆盖、范数、合成前后方向和数值复核。若这些证据支持进一步比较，再以相同候选坐标、当前64个anchor、原损失与训练预算，单独检验历史候选反传范围。不得把一次零更新诊断当成训练收益。

分块表示梯度再重算参数VJP是GradCache等已有方法的链式计算基础，见[梯度范围与原文核查](MSVR310_MEMORY_COORDINATE_VS_GRADIENT_BOUNDARIES_2026-09-07.md)。本页的链式法则与正交距离不变性都是标准数学事实，不作为本项目原创模块或新定理。
