# role-set v1：三折固定初始化真实参数梯度检查

2026-09-08登记；在CPU数学检查54a7d5a完成后进行。不是训练、全来源普查、完整M0或检索结果。

## 固定范围

复用现有MSVR310三折source-only完整路径隔离初始化、Signal/CLIP和原V8三角色；不读历史反传Q1 heldout结果选样本。每折仅执行既有seed42采样顺序的首8个B64，合计24batch/1536当前视图曝光。所有当前/历史数据仅来自该折source；记录每折实际独特record数，不声称覆盖全部source。

模型固定不更新，训练模式保留；每批末恢复BN等buffers，最终完整state hash相同。历史字段保存原anchor/reference/baseline和RNG；原队列容量512、年龄8，2批预热。这里年龄指批次距离，不是参数更新。各批计算两个目标作为诊断，包括尚未入队的前几批；未来真实训练预热前仍用原目标，不能混称本诊断为训练轨迹。

## 唯一被测机制

使用新鲜当前编码，原 fused hard vs role-set mean；两种目标均包含当前和历史一侧导数，仍只有当前64 anchor。三个角色提议使用同一次encoder/fusion实际输出的完整角色向量，不从fused近似重构，不对提议索引反传。其他13项loss此诊断不优化也不参与所报告的目标梯度；不能把该梯度称为14项总梯度。

对于每个固定batch：计算原目标、新目标与重复新目标的参数梯度；历史上游系数按原历史组重放并累加。报告各角色原/新完整目标梯度范数、余弦和差异，另报告重复新目标噪声。分别统计全部8批及含历史批的变化，不能用无历史批代替历史关系证据。第一个历史组用完整图直接反传验证分组VJP，沿用此前相对L2误差≤0.005的工程容差。保存全部4种距离矩阵、提议、逐anchor额外active计数和完整角色统计。

检查零更新历史fused/全部角色输出逐位一致，RNG状态不变，p.grad不被autograd.grad填充，buffers恢复，最终state hash相同。没有optimizer、模型保存、官方/heldout前向。

## 验证与后继

CPU根据全部24batch保存的四种距离、实际身份/历史记录重算正负mask、完整提议、去重数、hard和candidate标量及所有计数；核查梯度日志几何自洽。CPU不声称重新计算模型参数梯度，参数梯度仍为实际运行见证。工程命令完成不等于方法有效；若新梯度没有超过重复计算差异，先如实分析，不增大loss倍率救门。

完成后审计真实输出，才能决定下一项完整M0/配对训练合同；本脚本不自动启动训练、官方评估或消融，也不设检索晋级门。
