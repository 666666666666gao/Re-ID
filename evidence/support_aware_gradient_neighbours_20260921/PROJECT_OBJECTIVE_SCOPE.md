# 当前角色参数块上的目标范围

2026-09-21，root 根据当前已绑定源码进行静态调用图核对；未运行张量、模型或新的梯度诊断，也未修改训练。三篇近邻的作者方法与版本见 PRIMARY_SOURCE_NOTE.md / SOURCE_RECEIPT.json。本文件是项目代码推断，不属于论文作者结论或新的实测梯度分解。

## 13项是全局目标计数，不是每个角色收到13个独立辅助目标

`tools/run_signal_preserving_v5.py:99-135` 的加权总目标包括 fused ID/metric、三个完整角色 ID/Triplet，以及三个纯残差角色 ID/Triplet。移除 fused metric 后，O在全局定义上含7个ID和6个Triplet。

当前 V8 的可训练角色路径互不交换；尾部CLIP权重冻结，角色stage/head分别登记（`modeling/trifusion/signal_preserving_v8.py:265-339`）。各路径的运行与残差读取独立（391-463），完整分支只拼接冻结Signal和自身残差（494-517）；各ID头独立（570-611），criterion逐角色使用对应输出（714-741）。

所以对单个角色encoder参数块 θ_e，O_e的直接依赖来自以下五项：

1. fused ID；
2. 该角色完整分支ID；
3. 该角色完整分支Triplet；
4. 该角色纯残差ID；
5. 该角色纯残差Triplet。

其他两个角色各四项没有到 θ_e 的直接计算图路径。这里的“五项”是静态依赖数量，不保证每步五项均产生非零梯度，也没有重新测量各项范数或贡献。它不改变既有F/O诊断：`tools/probe_msvr_smooth_ap_objective_gradients.py:121-129`本来就是将triplet_fused置零后，对同一参数块求其余项的总导数。

因此不能从“1项对13项”推导13倍压制，也不能将O当作纯unimodal分类。MMPareto两个分类目标与本项目“排名对其余加权目标”是不同任务定义；即使两组共同下降，也不保证O内部每项分别下降。

## 后继候选的最低定义要求

若完整当前Q1后决定登记梯度调节，需明确：调整的参数块、F与O的完整目标、统计只在何种支持状态更新、历史VJP如何并入F、AMP下统计采用的真实尺度，以及实际AdamW更新的测量方法。固定终态范数比不能替代训练学习进度，也不能据此选一个固定倍率。

若各角色分别采用不同系数，需要如实称为参数块上的梯度调节；不能在没有推导的情况下称为某个统一标量加权loss的梯度。当前历史候选只对fused metric提供VJP，其余13项沿用当前batch监督；不是把整个历史集合变为额外ID任务或额外anchor。
