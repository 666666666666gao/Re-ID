# 梯度调节近邻：有界主源核查

核查日期：2026-09-21。范围仅 MMPareto、GradNorm、OGM-GE；只读论文及作者公开代码，未访问计算服务器、未运行模型、未修改训练或配置。结论为后继候选的设计边界，不是新颖性证明，也不是训练登记。

## 1. 结论与项目证据边界

三个先例分别支持把**方向冲突、梯度幅度、任务进展或贡献依据**明确分开；均不能直接决定本项目应把排名梯度放大多少。零合法 anchor 时维持原 13 项目标，是本项目的任务可用性合同；不是从这三篇论文获得的现成规则。

本次任务提供的已核事实：V8 冻结 Signal，CNN/Transformer/Mamba 为残差角色；F 是 current+history 联合排名目标在对应 encoder 上的梯度，O 是其余 13 项的聚合梯度。完整固定终态源诊断中，Smooth-AP 活跃角色批次 1755 个，F/O 反向 115 个，F/total 反向 37 个，角色 F/O 范数比中位数约 0.1055–0.1743。这里沿用任务给定事实，未再次读取原始诊断或观察训练进程；它不是原训练轨迹，也不是 AdamW 更新占比。跨 scene Smooth-AP 已通过 M0、正在执行固定 Q1 的状态同样来自任务交接，须保持其原合同。

主任务另行完成的本地代码核对：O 包含 id_fused、三组完整分支 ID/Triplet、三组纯 residual ID/Triplet，合计 7 个 ID 与 6 个 Triplet；诊断通过只将 triplet_fused 置零计算 O。因此 O 不是纯单模态分类辅助目标，不能把本项目 rank/其余13项直接等同于 MMPareto 的联合分类/单模态分类两任务。[项目损失定义](../../tools/run_signal_preserving_v5.py#L99)、[项目梯度诊断定义](../../tools/probe_msvr_smooth_ap_objective_gradients.py#L121)

## 2. MMPareto：论文与代码必须分开

**作者方法。** 对同一模态 encoder 的联合损失梯度 g_m、单模态梯度 g_u：非冲突 cos≥0 时等权相加；冲突时求凸组合最小范数方向 p=2αg_m+2(1−α)g_u，再取 h=γ‖g_m+g_u‖p/‖p‖。非冲突也乘 γ；实验 γ=1.5。p=0 是 Pareto 驻点边界。论文噪声论证依赖 SGD、梯度协方差等假设，不能视作任意任务的泛化定理。[原文 §3.3–3.4、算法1、§4.1](https://arxiv.org/html/2405.17730v1#S3.SS4)

**官方实现。** 在整个模态 encoder 上求权重，但逐参数张量恢复范数；排除 head。每个张量 j 实际为 h_j=1.5·max(1,‖g_original,j‖/‖p_j‖)p_j：只放大不缩小。分支使用 cos>0；cos=0 进入求解器。没有显式 p=0 停止分支。这与论文整体一次归一化及 ≥0 边界有差别。[固定 SHA 的 MMPareto.py，第74–84、149–207行](https://github.com/GeWu-Lab/MMPareto_ICML2024/blob/a339db39cc25b157df376b50bb894917dc6c01d6/code/MMPareto.py#L149)

求解器端点用 0.999/0.001 而非精确 1/0；二任务返回解析解。输入含各张量及其 concat，内积计算因此重复计数；在完整一致的两组张量上，所有内积同乘 2 不改变最小化权重。这是代码算术解释。[求解器第8–57、88–124行](https://github.com/GeWu-Lab/MMPareto_ICML2024/blob/a339db39cc25b157df376b50bb894917dc6c01d6/code/min_norm_solvers.py#L8)、[调用位置](https://github.com/GeWu-Lab/MMPareto_ICML2024/blob/a339db39cc25b157df376b50bb894917dc6c01d6/code/MMPareto.py#L169)

**本项目推断。** 整体正标量保留 p 的方向；不同张量使用不同标量会改变拼接后的方向。由 g_iᵀp>0 不能推出 g_iᵀDp>0（D 为正对角块缩放），所以不能把论文的整体共同下降论证直接挂到上述代码路径。即使采用精确整体方向，其一阶局部性质也不保证有限步、带动量或 AdamW 后的两个目标同时下降，更不保证 held-out mAP。γ 是整合后幅度倍率，不是“只把 F 权重设为 1.5”。

精确限定：这不表示该代码必然破坏共同下降，只表示原保证不能无条件继承。纯数学反例令两个坐标分别作为参数张量，g_R=(1,−2)、g_A=(−1,3)。两者内积 −7；最小范数凸组合的 α_R=17/29，故 p=2[α_R g_R+(1−α_R)g_A]=(10/29,4/29)，且 g_Rᵀp=g_Aᵀp=2/29>0。原和为 (0,1)，逐张量 max 规则把 p 改成 (10/29,1)，与 g_R 内积为 −48/29；再乘正的 γ=1.5 不改变负号。该例精确对应上述缩放规则，是代数反例，不是本项目观测、实验或对作者运行失败率的估计。

## 3. GradNorm：衡量训练进度后学习权重

**作者方法。** G_i=‖∇_W(w_iL_i)‖₂，W 通常选最后共享层；q_i=L_i(t)/L_i(0)，r_i=q_i/mean(q)。以 mean(G)·r_i^α 为目标，用 L1 差更新 w_i，目标项停止求导；网络按加权原损失更新。每步令 Σw_i=T，隔离总权重尺度与全局学习率。α=0 才追求相同范数；一般情形补偿相对较慢的任务，而非只看当前损失大小或梯度比。[PMLR 原 PDF，§3、算法1，PDF第2–4页](https://proceedings.mlr.press/v80/chen18a/chen18a.pdf)

**实现核查范围。** PMLR 论文页只给出正文/补充 PDF；本次有界检索未确认作者官方代码仓库，因此没有 GradNorm 官方实现 SHA、代码许可证或论文—官方代码一致性结论。不把第三方实现作为作者证据。[论文发布页](https://proceedings.mlr.press/v80/chen18a.html)

**本项目推断。** 固定终态梯度范数没有 L_i(0) 与训练历程，不能计算该方法的相对训练速度。把 O 的 13 项先合并为一个任务会改变任务定义；在完整 encoder 测量与在最后共享层测量也不是同一协议。没有合法排名样本导致的 L_rank=0，表示该批任务不可用；将其代入进度比并解释成“已经学会”，会混淆缺监督与进展。本文没有给出稀疏 anchor 的启停/重置合同；任何适配都属于项目新增设计。

## 4. OGM-GE：真实类别置信度与参数梯度噪声

**作者方法。** 从融合分类器分块估计单模态 logits，concat 情形分配 b/2；用每个样本**真实类别** softmax 概率的批内和构造模态比率 ρ。ρ>1 的优势模态乘 1−tanh(αρ)，另一模态保持 1。GE 加在 encoder 参数梯度上，论文写作协方差为 Σ_sgd 的高斯噪声；不是给输入、特征或损失值加噪。[原文 §3.2–3.3、式8–17](https://arxiv.org/html/2203.15332#S3.SS2)

**官方实现。** 只反传融合 CE；单模态 CE 用于记录。调节期内仅处理 audio/visual 的四维梯度张量。噪声逐元素采样，标准差为该张量未缩放梯度的元素 std+1e−8，未估计跨批完整协方差；系数为 1 的另一模态也加噪。ρ=1 时代码仍抑制 audio，论文应两者均取 1。[main.py，第94–151行](https://github.com/GeWu-Lab/OGM-GE_CVPR2022/blob/43aa7332e1dbb2fc84a0c5e5c36a19f710eba085/main.py#L94)

**本项目推断。** 参数元素间标准差与随机抽批产生的梯度协方差是不同统计对象。该实现支持研究“调节可能同时改变噪声”的问题，不能证明任意加噪改善本项目泛化。置信度比较依赖分类标签和可分解分类器，不能直接替换成排名梯度范数比，也不能把 CNN/T/M 角色简单当成作者的音频/视觉模态。

## 5. 可以保留的设计约束，不能推出的结论

以下是针对本项目的推断与合同，不是作者提出的新方法：

| 可以保留的约束 | 不能由现有证据推出 |
|---|---|
| 在同一明确参数块、同一损失定义下区分 F/O 夹角与范数 | 小范数就是学得慢、受压制，或全部批次都有冲突 |
| 方向修正与整体幅度控制分别说明、分别记录 | MMPareto 的 γ=1.5 适合本项目，或把范数比取倒数就是正确倍率 |
| 零合法 anchor 保持原 13 项；活跃性先由合法监督集合决定 | 零 rank 等于任务收敛；缺失任务可以当零损失参与均衡 |
| 对 F 与聚合 O 的约束只能声称保护这两个聚合目标 | O 改善意味着其内部 13 项逐项改善；角色间也自动共同下降 |
| 后继候选需要独立固定合同，使用真正训练中的统计检验 | 固定终态诊断已证明训练因果机制、最佳倍率或未知身份泛化 |

特别是 ‖Σ_j g_j‖ 会受 O 内部抵消影响；F/O 的中位比值不是 13 项总“优化预算”的分配比例。115 个 F/O 反向与 37 个 F/total 反向对应不同事件，不能互换。既有 Q1 的最终结果应按原协议闭合，任何梯度调节只能作为后继待登记候选；本次没有新增训练许可或实验。
