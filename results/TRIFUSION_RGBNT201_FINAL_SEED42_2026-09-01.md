## 训练与校准事实

- 训练：171 个身份、3951 个三模态记录；官方 query 836、gallery 836。
- 参数量：92,744,018；参数预算通过。
- epoch 1–7 为 `router_only`；epoch 8–60 为 `joint_hfer_urgc`。
- 训练总损失从联合阶段 epoch 8 的 12.9028 降至 epoch 60 的 0.8243。阶段切换前后的损失项不同，不能直接用其绝对值比较两个阶段。
- 训练集路由校准：BCE 0.5780、Brier 0.1946、ECE 0.01430；这是训练目标上的描述性端点校准，不是身份留出校准，也不支持因果或泛化校准主张。
- 路由的总体平均概率为 `0.24997075`，并且在七种退化条件、三个专家和三个模态之间几乎不变；它没有学出可用于选择专家的动态质量差异。`modality_missing` 是训练目标校准最差的登记场景（Brier `0.22338`、ECE `0.07178`），但这不是该场景的 ReID mAP。
- 所有七种登记退化条件的经验浓度覆盖率均不低于 0.90；query/gallery 对称性审计仍失败，不能主张交换对称性。

## 关键发现

1. **主目标未达到。** fused 比登记目标低 26.1522 mAP 和 24.6225 Rank-1，差距不是随机舍入或轻微调参能够解释的量级。
2. **融合存在信息瓶颈。** 当前融合把 3 专家 × 3 模态的九个 512 维贡献做加权求和，直接压成单个 512 维向量；作为参照，DeMo 推理保留三模态原始特征和七个 MoE 特征的拼接。当前路由又接近常数，因此融合实际接近均匀平均，CNN 的 mAP 和 Rank-1 反而略高于 fused。
3. **三专家发生同质化。** 三个融合投影在最终 checkpoint 中的两两余弦相似度均高于 `0.99992`；四路官方 mAP 最大差仅 `0.2813`。CNN/Transformer/Mamba 都由完全相同的共享 CLIP token 场起步，而私有多样性和同伴教学损失权重均为 0，现有协作更容易拉近表示，而非形成互补子空间。
4. **强预训练表示没有原样保留到检索头。** baseline 使用 CLIP 投影后的 CLS 全局特征并保留局部 token；当前 tokenizer 丢弃独立 CLS 输出，把 CLS 广播加到 patch 后再做 patch 均值，随后再投影。正式评估还使用 BN neck 后的 512 维向量，而 DeMo 配置使用 neck 前特征。这些都是结构/评测头差异，不等同于“继承 CLIP 后自然拥有 baseline 能力”。
5. **训练已收敛但明显过拟合。** epoch 60 的 fused ID loss 为 `0.01823`、triplet loss 为 `0.00562`，而官方 mAP 只有 `59.1478`；这排除了“只是没训练完”的主要解释。相较 baseline，当前没有 label smoothing，也缺少 camera SIE，且 60 个 epoch 中前 7 个只训练路由，都是泛化能力不足的次级因素。
6. **CNN 是当前最强单分支。** CNN 的 Rank-1 比 fused 高 0.4785，局部细节在该最终协议上至少没有被其他两支和融合超过。
7. **校准证据边界很窄。** 低总体训练 ECE 主要来自预测概率接近总体正例率，并不代表有区分度；缺少身份留出校准，不能证明身份外泛化。
8. **结果链有效但主张为否。** 原启动在官方评估后的路由审计因缺失导入失败；`repair-0002` 仅重算训练集路由审计，记录 `optimizer_steps=0`、`training_reexecuted=false`、`official_test_reexecuted=false`，官方评估计数保持 1。

## 下一步边界

遵守用户约束，不做消融、多种子或 baseline 复现。下一步只能是主方法恢复：

1. 新主版本先保留 CLIP 投影后的 CLS 与局部 token，并用可学习的保信息拼接/低秩交互替代九路直接加权求和；保持 512 维均值融合不能作为冲击高指标的主头。
2. 在 train/dev 范围内增加专家互补性门控，避免共享 token、共享投影初始化和 HFER 把三支训练成同一个表示；不访问本次官方 test。
3. HFER 的两次交换都使用第一次交换前后得到的同一份 stage-1 可靠性；最终融合虽然会刷新一次质量后验，但第二次交换仍使用旧后验。新主版本应在第二次交换前重新估计质量。
4. 若要主张 Mamba 特有跨模态传播，需要把跨模态状态传播放进 Mamba 路径；当前跨模态传播主要来自通用 HFER。
5. 统一训练/评估特征头，使用 train/dev-only 证据决定 neck 前后、CLS/局部组合和 label smoothing；不能用再次访问本次官方 test 的方式调模型。
6. 只有新主版本在预先冻结选择规则后，才可进行下一次独立正式实验；本次官方结果不得用于同一实验身份的继续选模。
