## 新观察及设计含义

1. 三集在“第一名仍正确”的query组均出现负向AP贡献，分别为−0.7204、−0.6395、−0.8743个百分点。首位修复与新增错误的AP贡献大体抵消后，这部分损害仍然存在。新增证据的评估必须覆盖全部合法正例排序，不能只看Rank-1、修复案例或最近正负间隔。
2. RGBNT100修复48条首位错误、产生45条新错误，R1净升0.1749点；但两者首位均正确的1584条query中，761条AP下降，使该组贡献−0.6395 mAP点。这具体解释了该端R1升而mAP降。
3. 新增首位错误主要出现在semantic原本正确、最近正负距离间隔最低的四分位：201为25/25，100为40/45，MSVR为22/23。与此同时，中高间隔组也有AP下降。因此仅保护低间隔首位，不能完整覆盖观察到的损害。这里间隔依赖真实标签，只作诊断，不是可部署置信度/Router，也不证明损害机制。
4. N1-high−原roles与EV1-combined−semantic同时AP下降的query为218、403、208条；同时下降的身份为11、16、21个。这是两种不同干预/不同控制及各自选点的描述性交集，不是共同控制因果估计、重复种子证据或真实部件错配标签。

下一项科学比较仍是匹配作者配方下的global_only/semantic/native，不加入新loss或恢复旧Router。第一模块若有效，先排除容量贡献，再验证对应和补偿；新读取器没有正式结果，不能由本次EV1复算判为无效。

用户已停止工程修复；本分析未做反向定位、显存修订、重算旧M0或GPU训练。原九端“先全部M0再正式训练”的执行条件与当前停止工程要求如何衔接，已向用户请求澄清，尚未将其擅自改为放行。
