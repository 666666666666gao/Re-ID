# Experiment Integrity Audit Prompt

An independent GPT-5.5 xhigh reviewer received only the paths to:

- final evaluation/data code;
- official metrics, access guard, checkpoint/fixed receipt, worker result, recovery, run identity and run summary;
- original failure receipt and `repair-0002` completion/tool snapshot;
- frozen config, directional authorization, data protocol/audit;
- the unified handoff document.

The reviewer was asked to check ground-truth provenance, score normalization, result existence, dead-code evaluation paths, actual scope, evaluation type, fake GT, phantom results, test leakage, official access count, optimizer steps during repair, and honest representation of the failed-launch/repair chain.
