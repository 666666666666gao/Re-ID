# 池化前 patch 对应监督：最小假说对照草案

日期：2026-10-07。research-refine 本轮最多2次独立上下文评审，READY阈值9保持。暂无人类校准锚点，CALIBRATION:none。此文是完整修订草案；尚无生产实现、实际M0或正式训练成绩。方法评审与最终代码审查分账，不把论文READY与有限可证伪试验混为一谈。

## Problem Anchor

- 最终问题：让新增分支为 RGB–NIR–TIR 身份检索提供 global 尚未解决的判别证据，最终在 RGBNT201、RGBNT100、MSVR310 三集上稳定超过匹配强基线，并按预训练资源与协议核实 SOTA；单集、工程通过和来源内拟合不能替代完整目标。
- 必须解决的瓶颈：分支活动、独立识别能力与最终排序净收益脱节。当前角色区域证据尚未证明能够在未见身份上修复 global 的错误而少添新错。
- 非目标：重复已闭合的容量、原生读取、轻量重建、slot/uniform、hard mask、独立头、detach、joint-L2、增量损失、gain、seed 或阈值搜索；不为论文预定三个有效模块，不把数学辅助目标改名当原创。
- 约束：仅 2026 物理 GPU0/1，一次一个 first6/last6 分段模型；现有 conda、数据与公开 CLIP 起点；不访问25/GPU2/3，不查询或设置温度功率，不安装环境。每个合格端独立真实8步M0后重新初始化完整50轮，同一 mAP-best 报告全部指标；失败端保留缺失；官方基准已参与开发须披露。必要权重与封存证据保留，无消费依赖的自训无用权重可退役。
- 成功证据：匹配配方、初始化、正式主训练批次和完整合法 query/gallery 的净收益；当前推进线保持 mAP 至少 +0.5 个百分点且 R1 不降。这只是研发决策线而非显著性；最终仍需强参照、完整流程多种子、机制必要性与实际成本。新单轮对照不等于完整目标完成。

## 问题与证据边界

§894已完成五端50轮及固定best的g/c/f分解：0/5主要配对、0/12全部配对晋级；201 repair相对同模型global仅+.3554mAP，MSVR近零，100 MD融合相对自己的global−.4586mAP。近容量语义、原生来源、patch/mean重建、slot/uniform分配、SIM mask/all-patch、头职责、读取detach及两类增量损失均不能重新列为待办。五个劣势自训best与10份特征缓存已在消费者闭合后退役，不可依赖旧75项物理seal。

实际semantic角色继承 FP32SlotCompetitionRoles：三个角色各自用全128个patch作key/value，16个query的softmax按模态独立归一化，positions参数未参与当前读取。CNN语义网格处理先于自身读取；CNN→Transformer→Mamba桥接发生于读取之后。原始作者增强对三个模态分别调用，不能把同坐标视为跨光谱部件真值。旧patch_memory local_support/full128也比较过，因此重新限制空间窗口不是新干预。

由此提出H2：池化前区域证据缺少可靠对应监督，可能使后续角色聚合难以形成可迁移的身份证据。结构支持这个可能性，但没有定位它为失分原因。最小实验仅问“同模态等变监督包能否改善分支的最终身份增量”。同模态增强匹配不是H2的必要前提；其成功不能确认H2，其失败也不能否定可靠跨光谱对应的所有路线。H2保留为未定位的上游假说，不作为这个低置信度试验的机制结论。

## 两条路线与选择

Route A：向现有池化前角色表示及其key投影施加已知同模态增强几何的dense对应辅助监督，不增加参数，维持原1536维部署、读出和raw职责目标。

Route B：CLIP文本空间反演/身份语义提示（DEEP/SAGA启发），增加语义依据。但改变外部资源、训练过程与推理计算，不能干净回答H2，也不能把之前轻量视觉重建重新包装为完整文本方法。暂不选。

A是有限假说检验，不预先声称顶会新颖性。若单纯对应辅助监督没有稳定净收益，则不能通过改温度/系数/视图/seed救分；关闭本假说实现并保留负结果。若有正结果，跨光谱内容组织及相同额外计算的控制另立合同，不自动加入。

## 最小机制

新增可训练组件：0。仅训练期添加第二个已知几何视图和一个dense辅助目标。复用当前shared CLIP、三角色key投影、raw职责头及读出gain，全部原优化器分组/学习率/采样保持。原global路径仍仅由global任务更新，辅助项不得反传主干/适配器/作者分类头。

主视图完全保持作者实际 Compose 输出与随机数消费。包装最后RandomErasing：先复制其输入，再原样调用原擦除器，用输入/输出逐像素相等记录未擦除支持；不重写擦除算法。实际作者主增强已有Pad(10)→RandomCrop，支持mask再保守剔除主视图外圈cfg.INPUT.PADDING=10像素，确保既有人工边界不进入aux；同时如实承认误剔了一部分真实内容。三个模态分别记录。Dataset/collate只新增训练侧sidecar，原五元组及原train_collate保持。真实车辆_eval_batch调用_training_batch，因此显式区分训练sidecar与原评价元组是当前调用证据要求，不是泛化fallback。

第二视图从已经生成的主normalized tensor构造，仅使用独立CPU随机源选择翻转和最多10像素的pad/crop平移；几何选择用独立random.Random(42)，状态随训练文本记录。第二no_grad模型forward用torch.random.fork_rng(devices=[0,1])保存并恢复CPU及两卡torch RNG；视觉可能仍有训练模式随机性，不能因no_grad就假定不消费RNG。主原随机流不得改变。擦除像素及pad区域的可见mask随几何映射一起变换。主模型先在当前权重上no_grad编码第二视图，只取三角色_depth_role和CNN空间处理后的key输入、key投影；不调用Mamba、作者head或BN，不保留第二视图激活图，再执行原主视图的唯一带梯度forward。借用的是同一当前模型的另一视图目标，不是EMA或独立教师。视觉/角色当前模式维持，RNG fork必须真实验证；buffer前后digest与作者BN单次计数须检查。

对两个16×8或8×16 patch网格，按已知像素几何及有效可见面积构造软对应目标。该目标是图像patch覆盖区的面积重叠，不能声称CLIP contextual token具有局部有限感受野；跨光谱不使用同编号patch标签。严格零重叠/不可见行不进入损失，未匹配质量的实际数量记录。

现有key投影得到128维学生K和停止梯度的另一视图K'。在每个样本、每个模态、每个角色内部：

    logits[p,j] = sqrt(128) * cosine(K[p], sg(K'[j]))
    L_dense = weighted_mean_p(-sum_j T[p,j]*log_softmax_j(logits[p,j]))
    L_total = 原raw职责global+角色身份目标 + 1.0*L_dense

scale=sqrt(128)、weight=1.0固定事前，不搜索。T按该学生patch在另一视图中可见覆盖量归一化，行权重按实际共同有效面积/256；9个role×modality损失等权均值。完全无共同可见支持的teacher列退出softmax分母；不是保留零value的假mask。零支持student行不参与均值，实际支持量逐步记录；不添加替代目标挽救无支持。aux选择自然反传整个pre-key路径：depth_logits、depth_norms、role_adapters、modality_embedding、CNN角色的cnn及key_projections；stage/global仍detach，所以不更新CLIP/共享adapter/作者head。上述角色输入也供value使用，因此aux会同时改变value所读内容，不能称仅更新W_K或不改value。query_projections/value_projections/readout/gain不是aux直接对象，主任务继续训练它们。原主任务8步更新门保持，aux VJP只要求真实参与的key投影有限非零及global路径无梯度。

部署与旧semantic完全一致：单视图g+c→L2，1536维、可离线建库、没有第二视图/新增参数/测试更新或标签。第二视图不是独立教师模型，不增加EMA/队列/新头。

## 近邻与新颖性

DenseCL是已存在的dense局部对比学习先例：作者方法利用backbone余弦最近邻取局部正对，联合global+dense InfoNCE、momentum和负样本队列；并非本方案的已知几何软目标。其检测/分割成绩不能移植到RGBNT预期。原文 https://arxiv.org/abs/2011.09157 ，作者实现 https://github.com/WXinlong/DenseCL 。已知增强几何监督本身也是已有思想，公式不作为原创。

更直接的近邻是PixContrast/PixPro（CVPR2021，https://arxiv.org/abs/2011.10043）：利用单图两个已知增强视图构造像素正对，PixPro另有传播与动量分支；本试验不复现其整套方法，也不声称几何对应公式原创。直接未验证的项目差别是让现有身份角色池化前的表示/K路径接受视图对应监督，而非新增读取容量或池化后分配。Normalized K–K匹配不会自动约束当前未归一化Q–K注意力；二者之间只是待证链条。没有可见对应/身份增量联动的证据，就不宣称身份语义解耦、可靠跨光谱部件匹配或论文主模块成功。

## 最小验证与执行交接

核心块2：三集各一个新variant，seed42、真实8步M0合格后fresh50、原raw职责目标和全部query/gallery。匹配旧raw-semantic控制分别74.3748615、84.0903051、50.5422249mAP，另报告独立global74.2966636、84.5337842、50.5421289。三集完整计划，不按中间官方成绩删除不利端；M0失败保留缺失，不重试挑通过。相同mAP-best同时报告全部CMC、末轮、完整曲线、修复/新增错误、身份收益与训练成本。机制跟踪包括有效对应行/列/像素支持、dense loss、几何目标下argmax命中质量、实际未归一化Q–K槽位权重的熵/可见质量/跨视图变化、key与pre-key参数变化。只记录，不用这些值改变scale、weight、视图或筛选正式端。Normalized K–K改善而Q–K没有变化必须作为未证链条报告；对应/熵/局部独立mAP均不能代替全量净检索收益。没有相应监督支持则按原M0标准关闭。

核心块3（只在前述结果稳定正向后另行登记）：保持同样有效支持/计算的空间置乱目标控制，分离监督内容；不现在堆叠跨模态新机制。aux=0的额外forward只是配对状态/RNG/输出检查，没有新学习信号，若该检查中性通过则不机械再训练三个闲置计算端。当前试验可以说明一个监督包是否有净收益，尚不能孤立几何内容的因果作用，也不能代替最终完整多种子。

## 当前剩余风险

- 同模态几何对应可能只学坐标/背景而非身份；对应准确不等于检索互补。
- 预训练token已含位置/全局语义，原key可能已近似对应；监督只是重复或不合任务，需首次M0描述实际支持而不据此改系数。
- aux自然反传会重塑供K/V使用的表示，但仍可能只保留坐标/背景，或者没有影响实际Q–K选择；本监督包的负结果不是H2全否定。
- 相同权重自视图目标仍可塌缩或压缩身份差异；不得靠熵/局部分类单指标宣称成功。
- 虽然0新增参数，额外视图/训练计算是实际资源改变，公开计入成本。
- 若审查判断机制根本偏离身份证据问题，先修订/放弃方案，不为了保持队列而启动。

## H2a 的唯一待检验命题及解释

唯一命题H2a：向现有semantic角色池化前表示加入上述固定同模态几何监督包，能否改善现有分支的净身份检索效用。主要配对固定为新variant−raw-semantic，不在independentglobal与own-g之间改选较易过线的分母。

正式best严格评价中同时收集当前模型own-global，与f使用同一批原图、一次视觉forward、同一query/gallery顺序和相同过滤；不额外再编码整个数据集。报告 f−own-g、own-g−independentglobal，以及f−rawsemantic三条不同边界；own-g不用于epoch或方法选择。距离摘要与完整query修复/新增错误/AP表保留，新增own-g距离计入三端2GiB缓冲。不拿旧已退役五权重做任何新诊断。

实际读取诊断用固定主视图Q分别查询主K和映射视图K'，保留原未归一化点积和scale，并在共同可见支持上比较权重及熵；只为观察K–K与Q–K的联系，不作为第二损失或晋级线。辅监督只见同图两个几何视图，不能解释成另一个camera/scene、未知身份监督或跨光谱真值。

预先固定结果解释：
- 对应代理改善而检索没有过线：关闭这个实现，几何一致性不足以改善当前身份增量；不能否定全部H2。
- 检索过线而实际读取链未获支持：保留经验收益，机制未定；不能宣称学到可靠身份部件。
- 三集过线且读取链方向一致：进入另行登记的内容必要性与完整训练多种子；一个seed的三集同向不叫训练稳定或SOTA。
- M0失败：保留缺失和实际失败，未训练不能填0或视为身份效能负结果；不重试挑通过。

前述状态/随机数中性检查不扩张为旧全模型反向重复性或Mamba工程修复。V6逐端8步有限梯度/真实更新/作者BN/完整state重载要求保持；历史parity失败不改判。所有输出仍以原单一mAP-best为准。
