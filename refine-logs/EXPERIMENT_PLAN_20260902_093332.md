# Experiment Plan

**Problem**: 将 V12 已证明的三专家互补转化为可部署融合增益。  
**Method Thesis**: 用 identity-OOF actual-path teacher 监督始终读取最终 all-fit deployment features 的 Router，并以 OOF replay 真实检索收益作为晋级门。  
**Date**: 2026-09-02

## Claim Map

| Claim | Why It Matters | Minimum Convincing Evidence | Linked Blocks |
|---|---|---|---|
| C1：deployment feature 可学习 OOF actual-path utility | 解决 V12 Router 监督/输入错配 | Q0 health/transfer全门；Q1每折不劣、aggregate cluster-bootstrap下界>0、OOF replay AP/margin真增益 | B1–B3 |
| C2：policy 可转化为部署主结果 | 回答方法是否值得继续 | 条件式一次 dev：fused≥65 mAP且严格胜 exact Signal、V8 Phase-B和三固定专家 | B4 |
| Anti-claim：增益不是 residual-only proxy 或 fold raw-coordinate 偶然 | 论文主贡献最小必要性 | 仅在C2成功后运行两项 deletion checks | B5 |

## Paper Storyline

- Main paper must prove: 三专家已有互补；actual-path paired distillation 可把它转成部署收益；exact Signal safety floor不变。
- Appendix can support: target health、transfer report、bootstrap receipt、质量/缺失模态响应。
- Experiments intentionally cut: baseline重跑、多种子、HFER、DINO、新backbone、alpha/LR/temperature/epoch/fold扫描、主结果前消融、official test。

## Experiment Blocks

### Block 1: 公共 seam 与真实 preflight

- Claim tested: 实现严格等价于冻结方案。
- Why this block exists: 防止 target、replay、final 各自实现不同 fusion。
- Dataset / split / task: CPU worked examples；远端 RGBNT201 fold0 少量真实样本，train-only。
- Compared systems: 无模型比较。
- Metrics: exact prefix、block order、removal-before-normalization、margin符号、bank immutability、sample pairing、bootstrap worked example、SHA绑定。
- Setup details: 公共 seams：`compose_v13_fused_embedding`、`counterfactual_query_utilities`、`identity_cluster_bootstrap_lower_bound`、Q0/Q1 gate、两个CLI。先RED后GREEN。
- Success criterion: 本地目标测试和远端相邻测试全通过；GPU<500MiB启动；preflight dev0/official0。
- Failure interpretation: 工程合同未闭合，不运行Q0。
- Table / figure target: implementation receipt。
- Priority: MUST-RUN

### Block 2: V13-Q0 paired actual-path target qualification

- Claim tested: OOF action utility在真实融合路径非退化，且动作语义能转移到deployment expert slots。
- Why this block exists: V12 residual-only Oracle不能直接证明最终融合效用。
- Dataset / split / task: RGBNT201 141-fit固定3-fold，571 eligible queries；无dev/official。
- Compared systems: uniform full path、九个query-side slot removals、OOF-oracle action与train-fold fixed action的all-fit只读transfer。
- Metrics: 每槽Delta分布/positive ratio/entropy/unique wins；Oracle-minus-fixed；bank SHA；OOF/all-fit sign/top1/Spearman report；binary transfer gate。
- Setup details: 复用V12三折checkpoints和V8 Phase-A；alpha0.2；只前向，不训练教师；paired cache存query+gallery的teacher/student feature。
- Success criterion: 三专家/三模态unique positive；Oracle>fixed；所有健康门；transfer per-fold non-inferior且aggregate strict win；dev0/official0。
- Failure interpretation: action semantics或actual-path互补不成立，封存V13。
- Table / figure target: Q0 target-health/transfer表。
- Priority: MUST-RUN

### Block 3: V13-Q1 identity-heldout policy + OOF replay

- Claim tested: fixed deployment features 能预测 OOF utility，并产生真实 non-saturated retrieval gain。
- Why this block exists: 直接决定是否允许dev。
- Dataset / split / task: 同一141-fit 3-fold；student extractor all-fit冻结；target/replay identity-heldout OOF。
- Compared systems: learned Router vs train-fold-selected fixed slot/majority。
- Metrics: expected Delta、Top1、OOF replay per-query AP/Rank1/margin；identity-cluster paired bootstrap；quality/missing mass。
- Setup details: seed42；100epochs/fold；LR3.5e-4；hidden128；temperature0.05；quality weight1；alpha0.2 fixed；无专家训练。
- Success criterion: 每折四类指标non-inferior；aggregate Delta/Top1/AP/margin的10k identity-cluster bootstrap 95% lower bound>0；quality全通过；冻结SHA不变。
- Failure interpretation: policy不可部署，封存V13；不refit、不dev、不扫描。
- Table / figure target: Q1 policy/replay gate表。
- Priority: MUST-RUN（仅Q0通过）

### Block 4: 单次 frozen dev 主结果

- Claim tested: V13能达到当前内部主目标。
- Why this block exists: 唯一部署证据。
- Dataset / split / task: 固定30-dev；一次final-only evaluation。
- Compared systems: exact Signal `58.0109`、V8 Phase-B `58.4050`、V13 fused/CNN/Transformer/Mamba。
- Metrics: mAP、Rank-1。
- Setup details: Router在全部paired rows final refit；Phase-A SHA与cache严格一致；alpha0.2；无rerank。
- Success criterion: fused≥65 mAP且严格超过全部登记输出。
- Failure interpretation: 不访问official、不做消融、不声称SOTA；V8 Phase-B仍为deployable best。
- Table / figure target: main result table。
- Priority: MUST-RUN（仅Q1通过）

### Block 5: 两项 claim-critical deletion checks

- Claim tested: actual-path target与deployment-paired input均为必要。
- Why this block exists: 仅在主结果成功后支撑论文novelty。
- Dataset / split / task: 与成功主结果相同冻结协议。
- Compared systems: `actual-path→residual-only`；`paired deployment input→fold raw input`。
- Metrics: Q1 OOF replay与dev mAP。
- Setup details: 不增第三项，不扫描参数。
- Success criterion: final method严格优于两个删除版本。
- Failure interpretation: 收缩对应claim。
- Table / figure target: minimal ablation table。
- Priority: NICE-TO-HAVE/BLOCKED，直到B4成功

## Compute and Data Budget

- Total estimated GPU-hours before dev: `0.15–0.4`；不含实现时间。
- Data preparation needs: 0；使用现有RGBNT201和固定fold/sample order。
- Human evaluation needs: 0。
- Biggest bottleneck: OOF teacher slot utility能否迁移到all-fit deployment experts，而非显存；RTX3090当前余量充足。

## Risks and Mitigations

- all-fit student interface见过fit identities：claim严格限制为policy validation；target与replay仍identity-heldout OOF。
- uniform-bank target与per-sample routing不同：Q1 learned query/gallery OOF replay mAP/margin为硬门。
- 统计样本簇约21个：bootstrap只作保守内部晋级门，不宣称定论；最终证据仍是30-dev。
- cache/checkpoint错配：所有阶段hard assert Phase-A/fold checkpoint/feature/order SHA。
