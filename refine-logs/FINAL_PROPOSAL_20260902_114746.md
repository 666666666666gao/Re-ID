# Research Proposal: TriFusion V15 — Counterfactual Role-Delta Exchange

## Problem Anchor

- **Bottom-line problem**：在固定 RGBNT201 `141-fit / 30-dev` 协议上，让共享
  CLIP 语义主干上的 CNN、Transformer、Mamba 三个架构专家产生真正的深层
  相互促进，使部署 fused 严格高于 exact Signal 和三个分支，并达到至少
  `65 mAP`；只有同协议结果确实达到公开最佳时才宣称 SOTA。
- **Must-solve bottleneck**：V8 已证明三个专家有 query-level 互补，但选择
  Oracle 也只有 `64.7850 mAP`；V13/V14 证明 sample-local Router 不能稳定预测
  held-out relational utility；V9 又证明在池化残差之后追加 relay 会破坏
  identity-disjoint 泛化。必须生成当前固定分支之外的新身份表示，而不是再次
  调 Router 或在末端堆一个 embedding mixer。
- **Non-goals**：不复现 Signal baseline；不扫描 Router、alpha、LR、epoch、
  temperature 或 exchange 强度；主结果通过前不做消融、多 seed、official test
  或 reranking；不增加 DINO/文本/额外 backbone；不把 diagnostic Oracle 当部署
  结果。
- **Constraints**：所有训练和评估仅在远端单张 RTX 3090 24GB；seed42；共享
  三模态几何增强；真实 B64/K8；exact Signal 3072D 输出逐元素保留；复用 V12
  三个 complete-path identity-OOF Signal/expert checkpoint 和 V8 all-fit Phase-A
  checkpoint；主实验前先过 train-only identity-disjoint 门。
- **Success condition**：新的 stagewise collaboration 在每个完整路径 OOF fold
  上不劣于同 checkpoint 的 no-exchange bank，query-weighted mAP 有预注册正
  增益且 identity-bootstrap 下界为正；随后唯一 all-fit seed42 frozen-dev 结果
  fused `>=65 mAP`，并严格高于 exact Signal、no-exchange bank、CNN、
  Transformer、Mamba。

## Method Thesis

V15 的唯一贡献是 **Counterfactual Role-Delta Exchange (CRDE)**：只交换 CNN、
Transformer、Mamba 在当前 frozen CLIP tail stage 上由 role adapter 新产生的
delta，在下一 frozen CLIP tail 前以有界 peer residual 注入并保留 receiver 私有
恒等路径；训练时用同一增强 tensor、完全无状态的 no-exchange pre-BN retrieval
embedding 构造 matched regret。

V8 pretrained-tail rebranching、Signal exact prefix、role adapters/heads、fusion
与 evaluator 都是冻结 substrate，不列为 V15 新贡献。V15 不含 Router、learned
alpha/beta、第三层 exchange、末端 synthesis MLP、orthogonalization、额外
backbone、teacher、文本或 reranking。

## Architecture

```text
shared-geometry RGB/NI/TIR
          |
 frozen Signal -> exact baseline z0
          |
 CLIP block8 anchor
          |
 frozen tail9 -> C/T/M adapters -> role delta D1 -> CRDE exchange 1
          |
 frozen tail10 <- private state + bounded peer delta
          |
 C/T/M adapters -> role delta D2 -> CRDE exchange 2
          |
 frozen tail11 <- private state + bounded peer delta
          |
 matched final heads -> C/T/M residual bank
          |
 [exact z0, equal-energy normalized bank]
```

对 stage `l∈{1,2}` 与 source expert `s`：

\[
D_s^l=Y_s^l-X_s^l,
\qquad
\widetilde Y_t^l=Y_t^l+
\sum_{s\ne t}0.25\tanh(\theta_{s\to t}^l)P_{s\to t}M_s(D_s^l).
\]

`X/Y` 是 role adapter 前/后 token。CNN mixer 在 rank64 patch grid 做 depthwise
2D local mixing；Transformer mixer 对 rank64 CLS+patch delta 做 self-attention；
Mamba mixer 对 rank64 patch delta 做 four-direction spatial 与 aligned modal
scan。六条 directed peer edges 独立投影、同步更新、无 self-edge。`theta=0`
初始化，通信系数绝对值固定不超过0.25。CRDE 不对 receiver full state做新
LayerNorm、正交化或能量匹配。tail11 后不交换，保证两次 injection 都由后续
pretrained tail 解释。

最终沿 V8 matched reference/head 得到 residual bank：

\[
z_{fused}=[z_0,\|z_0\|\operatorname{Normalize}
(\operatorname{Concat}(r_C,r_T,r_M))].
\]

`z0` 必须逐元素等于 exact Signal；推理不使用 classifier、Router 或 sample
scalar。

## Frozen/Trainable and Counterfactual Contract

每个 Q1 fold 或 D1 run：

- 对应 V12 fold-specific 或 V8 all-fit Signal/V8 experts 全冻结并 `eval()`；
- 只训练两层 CRDE 和该 run 新建的 on-path BNNeck/classifier；classifier 只覆盖
  source training identities；
- heldout/dev evaluation 绕过所有 BN/classifier，使用 pre-BN retrieval embedding；
- on-path 可穿过 frozen ops 向 CRDE 反传，frozen parameter/buffer 不更新。

loader 每个 batch 只执行一次 transform，off/on 接收同一组 tensor objects：

1. `off` 调用原 frozen V8 base，`eval()` + `torch.no_grad()`，返回 detached
   pre-BN baseline/fused/C/T/M；不调用任何 V15 BN/classifier；
2. `on` 用相同 tensors 执行两层 CRDE；ID loss 只调用 on-path heads。

对四个输出 `o∈{fused,C,T,M}` 的 L2-normalized pre-BN embedding，计算物理
B64/K8 内 cross-camera hardest-positive / nearest-negative softplus risk：

\[
R(z)=|Q|^{-1}\sum_{q\in Q}
\operatorname{softplus}(d^+_{hard}(q)-d^-_{near}(q)).
\]

总损失冻结为：

\[
L=L_{V8,on}+\lambda_{regret}\frac14\sum_o
\operatorname{softplus}(R(z_o^{on})-
\operatorname{stopgrad}R(z_o^{off})),
\quad \lambda_{regret}=1.0.
\]

`REGRET_WEIGHT=1.0` 必须在 config/builder/criterion/runner/receipt 一致，不扫描；
同样不扫描 edge bound、epoch、LR、temperature 或 margin。

## Execution Gates

### M0 Engineering

- 两层同步无 self-edge，step0 on/off exact；
- off/on keys、shape、storage data pointer 相同；
- off forward 的 V15 BN/classifier hook count=0；
- frozen parameter/buffer SHA 与 BN running stats 前后不变；
- heldout evaluator只读 pre-BN；exact Signal prefix；
- regret contract=1.0、finite gradient、两次 exchange live path；
- remote real B64/K8 8-step capacity 和100-step fixed-batch overfit。

### Q1 Complete-Path Identity-OOF Authorization

复用 V12 三个 fold checkpoint。每折 base 和 CRDE 都只见94 source identities；
CRDE/heads训练20 final-only epochs，在47 heldout identities 上只评价 pre-BN。
总计21个 cross-camera eligible identities、571 queries。no-exchange 必须是该 CRDE
run 所加载的**同一 fold base/checkpoint SHA**，仅禁用 CRDE；记录所有 IDs、SHA
和 access counts。

全部门通过才授权 D1：

- 三折 fused mAP gain 均 `>=0`；
- 571-query weighted fused mAP gain `>=1.0`；
- 21-identity cluster bootstrap 95% lower bound `>0`；
- aggregate C/T/M matched mAP gain 各 `>0`，每折至少两个 receiver `>0`；
- aggregate fused 严格高于三个 on branches；
- M0/state/access/fold-isolation contracts 全通过。

Q1 只支持 train-only mechanism qualification；不支持65、部署、official或SOTA。

### D1 Sole Deployable Main

仅Q1通过后，加载 V8 all-fit Phase-A，冻结 base，以相同 seed42、B64/K8、
CRDE、`REGRET_WEIGHT=1.0` 和20 final-only epochs训练；随后 frozen checkpoint 对
30-dev只评价一次。

晋级要求：fused `>=65 mAP`；mAP 严格高于 exact Signal、frozen no-exchange V8
bank、CRDE C/T/M；Rank-1严格高于三个 branches；official0。失败即封存，不
扫参、不消融、不多seed。成功后才允许 no-exchange/full-state/without-regret
三项最小消融和一次 official-protocol 评估；同协议真实超过公开最佳前不称SOTA。

## Novelty and Claim Boundary

不能声称多分支、深层 exchange 或 CNN+Transformer+Mamba 组合首次。CRDE 的
窄区别是：通信内容只含 matched role-adapter delta；位置只在下一 frozen CLIP
tail 前；receiver private state 是恒等主路径；训练比较同一增强 tensor 上无状态
pre-BN no-exchange relational risk。这区别于原 HFER full-state relay、
FusionReID transfer、V9 pooled orthogonal synthesis 和 V13/V14 Router。

READY 只表示本方案可实施，不支持任何新指标。Q1失败即封存；Q1通过只授权
D1；D1 是唯一部署主张来源。
