# 实验计划

**问题**：RGB–NIR–TIR 多模态目标重识别中，如何让 CNN、Transformer、Mamba 三个完整架构专家真正互促，并在传感器质量变化或缺失时保持可信检索。
**方法主张**：三个独立可检索的异构专家通过 HFER 深层交换；一个由身份外折真实干预监督的 CIRC 后验，再由 URGC 同时控制中继与融合。
**日期**：2026-08-31
**版本**：v1.2，已纳入最近六个月查新、四轮独立 GPT-5.5 xhigh 复核，以及结果前 quantitative claim-gate 冻结；implementation-readiness PASS
**实现底座**：DeMo commit b4f323a430b32e3a1637c3e7acb25868cb52e9cd
**可测强锚点**：MDReID commit 3525ac2da1a2a90a5a160c930fac674b4f226f6c，本机 82.0868 mAP / 85.1675 Rank-1
**公平 SOTA 门**：RGBNT201，静态 CLIP-B/16，256×128，无 reranking、TTT、文本或测试选点；当前注册下限为 RoDI-CLIP 84.1 mAP / 87.2 Rank-1。正式 claim 前必须刷新同赛道公开结果（特别是当前只有占位仓库的 Hyper-ReID），三固定种子同时超过刷新后的两个门槛，并通过实验完整性审计。

## 预注册判定规则

机器可读的唯一阈值源是 `protocols/claim_gates_v1.json`，SHA-256
`2ca8badf75d2e2b6ad83f92cd36f18eec2bb74320d872e62ad51b30ed6f813e4`。
它在任何 R020+ 方法结果产生前冻结；后续若必须修改，只能在读取结果前
新增版本并保留 v1，禁止覆盖。

所有 retrieval 差值均为 candidate−comparator 的百分点。开发与最终可配对
比较使用 10,000 次 identity-cluster paired bootstrap（同一身份的全部 query
一起重采样）和 100,000 次 identity-cluster sign-flip permutation；不得把
单 query 或 corruption seed 当作独立样本。每个主张家族内使用 Holm
校正，`alpha=0.05`。点差、置信区间和校正后检验必须同时过门；只过其中
一项不能晋升主张。

| 组件 | 最低可发表门 |
|---|---|
| HFER | 同时对 A1 与参数/FLOPs 匹配 A4：fused ΔmAP≥+0.50 pp、ΔR1≥+0.30 pp，95% cluster CI 下界>0、Holm p<0.05；至少两个接收分支各自 ΔmAP≥+0.30 pp 且 CI 下界>0；目标 trainable gradient coverage=100% |
| CIRC | 同时对 R0/R1/R2/R4/R5：fused ΔmAP≥+0.50 pp 且 CI 下界>0；R1 以 −0.30 pp 为非劣界；helpfulness macro-AUROC≥0.65，Brier 相对 observational 至少改善 5%，overall ECE≤0.05，只有 identity-cluster N_eff≥20 且 rows≥200 的组才允许 group-ECE≤0.10 主张；预测与 total effect 的 Spearman 点估计≥0.30、CI 下界≥0.10 |
| URGC | 同时对 U0/U1/U3：fused ΔmAP≥+0.30 pp 且 CI 下界>0；R1 非劣界 −0.30 pp；至少两个分支各自 ΔmAP≥+0.30 pp；完整模态非劣界 −0.30 pp，七 mask 平均/最差 mAP 至少 +1.00/+0.50 pp |
| CIRC 外部有效性 | query-gallery symmetry 和 proxy→deployed transfer 均要求 Spearman≥0.50、符号一致率≥70%；腐化单调 cell 比例≥80%，severity→reliability Spearman≤−0.50 |
| 负控制 | shuffled target、expert permutation、identity/camera leak probe 和 context-free floor 的增益不得超过 promoted gain 的 50%，且不得出现 Holm-corrected 正增益 |
| RDPT（可选） | K3 对 K0/K1/K2/K4 fused ΔmAP≥+0.30 pp、至少两个分支改善；reject rate 严格位于 5%–95%，不得发生 private-CKA collapse；否则不晋升 |
| SOTA | R071A 只允许抬高门槛；三个固定 seed 的 mAP 与 R1 每一个都必须严格超过投稿日刷新值。对没有逐 query 输出的论文值不伪造显著性检验 |

ECE 固定 15 个 equal-frequency bins；异质 corruption family、severity 和
seed 绝不池化为 iid 样本。上述数值是主张晋升下限，不是调参目标。

## 三个技术部分与论文定位

1. **HFER**：三个完整架构专家都处理 RGB/NIR/TIR，在两个中间深度进行同步、角色保持的低秩双向 relay，并保留私有残差和独立检索头。
2. **CIRC**：三折身份外折的 HFER-uniform 冻结生成器，通过全量 expert×modality total/direct/relay 移除和哈希采样 relay-edge 审计的完整重跑生成共同尺度效用 target；一个 shared-output global joint Beta router 输出九项 posterior。
3. **URGC**：同一 CIRC posterior 同时控制 HFER 消息带宽、最终 expert×modality 融合和缺失/退化抑制。

CIRC 与 URGC 是一个统一可靠性贡献的“如何学”和“如何用”，不作为两个互不相关的“首次”包装。RDPT 保留为可删辅助：只有硬消融显著优于已有 selective/adaptive KD 且改善弱分支、不造成 CKA 坍缩时才晋升。

## Paper Storyline

- 主文必须证明：协议和 baseline 可信；HFER 改善分支而非只改善融合；CIRC 后验与外折真实干预一致；同一后验复用优于分裂路由器；完整/缺失/退化与效率形成闭环。
- 附录支持：router 温度、relay rank、stage 数、不同 corruption 强度、RDPT 辅助、更多 CKA/可视化和跨数据集完整表。
- 明确裁剪：大规模无假设网格；弱基线堆表；额外文本/SAM/TTT；使用 official test 选择结构、阈值或 epoch；把 RDPT 强行保留为主创新。

## Experiment Blocks

### Block 1：协议、指标与 baseline 闭环

- Claim tested：所有后续比较基于正确协议、固定资源和可重算基线。
- Why this block exists：DeMo 上游每 epoch 读取 official test 并按 test mAP 写 best，必须与公平 fixed-epoch 结果分开。
- Dataset / split / task：RGBNT201 train_171；官方 test query/gallery；141-fit/30-dev 仅用于选配置。
- Compared systems：主强 checkpoint baseline 为 MDReID 官方权重（本机 parity 82.0868 / 85.1675）；DeMo 仅作为已接入实现脚手架并报告 fixed DeMo_50.pth；PEFT-BoA 从头复现并分栏报告 fixed e120（主行）与 released-log test-selected e80（校准）；Signal、MFRNet checkpoint 作为可执行补充比较器；所有 test-selected best 都不得进入公平主行。
- Metrics：mAP、R1/R5/R10、完整性门、checkpoint SHA、训练/评估延迟。
- Setup details：CLIP-B/16、256×128、B32/K4/TB64、50 epochs、seed 42；官方 same-id/same-camera 排除。
- Success criterion：MDReID parity 误差 ≤0.3 pp；DeMo 50 epoch 完整无 fatal/nonfinite；PEFT-BoA B64/K4 先过容量门，再以 seed1111 固定训练至 e120，训练期不读取 official test，主行对照公开 fixed-e120 82.2/85.8 而非 test-best 82.7/86.1；若未达到则保留失败证据而不降格对手；fixed 与 test-selected 标签绝不混用；手算 evaluator 回归通过。
- Failure interpretation：先诊断 evaluator、数据、权重或环境；不得把偏低复现当弱对手。
- Table / figure target：复现表与协议附录。
- Priority：MUST-RUN。

### Block 2：HFER 主结果和 branch-preserving 证据

- Claim tested：HFER 让三类完整专家产生可测互补，而非末端堆叠。
- Dataset / split / task：RGBNT201 141-fit/30-dev；晋级后全 171 重训。
- Compared systems：CNN-only、Transformer-only、Mamba-only、三专家 mean、concat+MLP、HFER-uniform、单 stage relay、单向 ring relay、source-role mixer permutation、无 private residual、无 role mixer、两专家子集、至少一个参数匹配同构三专家控制、参数/FLOPs 匹配大 MLP 与 widened single-backbone 控制。
- Metrics：fused 和每 branch mAP/R1；错误重叠；CKA/私有能量；参数、FLOPs、梯度覆盖、显存。
- Setup details：共享 tokenizer 和相同预训练边界；所有控制使用相同训练预算和 512-d 最终 embedding。
- Success criterion：严格通过 claim-gates v1 的 HFER 点差、identity-cluster CI、Holm 检验、两分支和 100% 梯度覆盖门；单 stage、单向和 role permutation 不能解释完整 HFER 增益。
- Failure interpretation：若只改善 fused head，则 HFER 降级为 feature fusion；若 matched control 相当，则删去复杂 relay 叙事。
- Table / figure target：主架构表、branch-before/after 图。
- Priority：MUST-RUN。

### Block 3：CIRC/URGC 新颖性、因果和简洁性隔离

- Claim tested：可靠性不是 self-referential gate；一个 posterior 的统一控制优于更碎片化设计。
- Dataset / split / task：三折身份外折 fit target；30 dev 只做冻结校准审计。
- Compared systems：softmax；expert-only、modality-only 和同容量 scalar gate；observational joint Beta；cheap head-only LOO；CIRC full OOF intervention；九个独立 evidence heads；TMUR-style global non-evidential router；TIGER-style whole-expert exclusion；fusion-only；relay-only；separate matched routers；temperature rescaling；shuffled targets；expert permutation；identity/camera leak probes；context-free capacity floor。
- Metrics：fused/branch mAP/R1；helpfulness AUROC；全量 total/direct/relay signed effects、interaction residual 与 audit-only sampled-edge effects；helpful/neutral/harmful signed strata；full-intervention utility Spearman 与 high-vs-low quartile effect；cheap-vs-full signed/rank agreement；逐 family×severity×seed BCE/Brier/15-bin equal-frequency ECE（整体与 expert/modality/camera/identity-frequency 分组）；过度离散、经验 concentration coverage、identity/query-cluster effective sample size、query-gallery 对称性、proxy-to-deployed transfer、路由熵。
- Setup details：target generator 与 router/fusion 参数隔离；target row 的 identity 不在 generator training fold；主行必须有不同相机正样本；冻结 held-out embedding 构建固定非参数 identity reference bank，不使用 unseen ID classifier weight；fold、epsilon、corruption suite、encoder config、cache schema/code、metrics、checkpoint、seed、edge salt/order/validity/two-per-row budget 和 agreement gates 在 target 生成或读取 dev label 前全部冻结并哈希；异质条件不得合并成 iid trial；最终配置冻结后原 30 dev 仅作为 all-171 training rows 回流，禁止再次选型或早停。
- Success criterion：严格通过 claim-gates v1 的 CIRC retrieval、AUROC/Brier/ECE、effect-alignment、symmetry/transfer 和负控制门；同一 posterior 还必须通过 URGC 对 U0/U1/U3 的点差/非劣门。r 仍只声称 helpful-vs-not-helpful，neutral/harmful 仅作有符号审计。
- Failure interpretation：校准失败则只称 dynamic gate；separate routers 不差则删除 unified-control 主张；cheap/full 不一致则禁用 cheap 辅助。
- Table / figure target：核心消融表、reliability diagram、干预散点。
- Priority：MUST-RUN。

### Block 4：缺失、退化与跨数据集

- Claim tested：同一 posterior 在完整和不完整输入下都有效，不是只记住固定模态偏好。
- Dataset / split / task：RGBNT201 七种非空 mask；RGB/NIR/TIR blur、occlusion、exposure、sensor noise；MSVR310 和 RGBNT100 作为外部验证。
- Compared systems：MDReID、DeMo、复现成功后的 PEFT-BoA、Signal、UGG-ReID、RoDI/FUSE/MGRNet 报告上限、Miss-ReID；HFER-uniform、CIRC/URGC、separate routers。
- Metrics：完整 mAP/R1、mask 平均/最差、robustness AUC、性能保持率、分组 ECE、corruption monotonicity。
- Setup details：corruption family、强度和 seeds 在训练前注册；缺失与低质量但存在的模态分开报告。
- Success criterion：完整模态 95% identity-cluster CI 下界高于 −0.30 pp；七 mask 平均/最差 mAP 至少改善 +1.00/+0.50 pp；至少 80% 已注册 corruption cells 的可靠性单调，severity→对应 reliability Spearman≤−0.50；至少一个第二数据集方向一致。
- Failure interpretation：只对训练见过 mask 有效时，将主张限制为 modality-dropout robustness。
- Table / figure target：鲁棒性表和退化曲线。
- Priority：MUST-RUN；第二数据集三种子为 NICE-TO-HAVE。

### Block 5：正式统计、效率、失败分析与 SOTA 审计

- Claim tested：收益稳定、资源透明、结论不超出证据。
- Compared systems：固定 strongest baseline、promoted core、matched control；RDPT 仅作为可删 appendix variant。
- Metrics：三种子均值±标准差；identity-cluster paired bootstrap/sign-flip permutation 与 Holm family correction；params/FLOPs/fps/VRAM；失败类型；claim audit。
- Setup details：seeds 42/3407/9199；配置在 dev 冻结；原 30 dev 随后仅作为 training rows 回流并全 171 从头重训，禁止再次选型或早停；每 seed official test 一次；无 rerank/TTT。
- Success criterion：每个 promoted claim 通过自身门；正式写作前完成一次有时间戳的同赛道主源刷新，以 `max(84.1/87.2, 新公开同协议门槛)` 分别更新 mAP/R1 门；只有三种子同时超过刷新后的两个值才写 SOTA。
- Failure interpretation：未过 SOTA 门仍可报告机制结果，但不得缩小或改写比较协议。
- Table / figure target：Table 1、效率表、统计附录、失败图。
- Priority：MUST-RUN。

## Compute and Data Budget

- 当前单卡：RTX 4060 Laptop 8,188 MiB；AMP、activation checkpointing、有效模态 pack 为默认。
- Baseline DeMo B32/K4 实测 8-step 峰值 6,894.18 MiB；R012 从 03:48:14 到 epoch31 train 完成 07:23:22，约 3.59 h（含逐轮三路评估），线性外推 50 epoch 约 5.8 h，但该值不外推为 TriFusion 时长。TriFusion 设计门为 real B32/K4 ≤7,600 MiB。
- v1.2 保留三折 target generator 与离线完整干预，完整论文总预算约 550–1,100 GPU-h；即单卡理论连续 23–46 天，若 GPU 只有 50% 可用则约 46–92 天。实际必须在 M2 以 HFER 单 epoch 和 intervention throughput 重估，不把估计写成已用算力。
- target 构建顺序执行干预并缓存标量，不同时保留多个完整图；T/D/R 对九项全量重跑，edge 仅每 row 每 stage 哈希抽一条（两次额外前向，而非 36 次），这降低显存和成本而不把抽样审计伪装成全边 target。
- 数据：RGBNT201、MSVR310、RGBNT100 均已下载并通过全量审计。
- 最大瓶颈：本地单卡时间，其次是 target cache 生成；不得用 official test 曲线节省 dev 选择成本。

## Risks and Mitigations

- **HFER 只是更大 ensemble**：branch-before/after、matched params/FLOPs、两专家和无 relay 控制。
- **TMUR 可比性问题**：共同目标、共享输出函数、分组校准、共同温度/concentration prior、independent-head 负对照。
- **target 与 router 共适应导致循环**：身份外折冻结 generator、跨相机固定 reference bank、四类完整重跑干预、不可变 cache、router 不反传 target、最终部署模型 target-transfer 审计。
- **causal routing 已有 TIGER/MRUF/TIER 先例**：不声称首次；只检验 RGBNT retrieval、expert×modality、relay-edge 与跨位置复用的窄差异。
- **RDPT 新颖性不足**：默认移出 promoted core；只在硬消融通过后进入 appendix 或贡献讨论。
- **8 GB/OOM**：先 tiny/一批/B32 8-step 门；checkpointing 和 serial intervention；不删专家或偷换真实 batch。
- **单种子偶然增益**：单种子只做决策，promoted 结果固定三种子，并用 identity-cluster paired tests；单 query/corruption seed 不作独立样本。
- **SOTA 资源混排**：CLIP、DINO、额外语义、multi-stage KD、TTT 分轨报告。
- **阈值后见之明**：claim_gates_v1 在 R020+ 结果前冻结；任何替代只能在读取结果前产生新版本并保留 v1，禁止回写。
- **SOTA 前沿移动或占位论文补发**：R071A 在最终 claim 审计前重新检查 RoDI、Hyper-ReID、作者主页、会议/期刊正式页和官方仓库；新同协议结果只会抬高门槛，不会被忽略或降格。
