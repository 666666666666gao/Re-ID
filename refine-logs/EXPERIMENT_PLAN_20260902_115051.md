# TriFusion V15 Experiment Plan

**Problem**：把 V8 已观测到但无法被 Router 利用的 CNN/Transformer/Mamba
互补性，转化为新的 identity-disjoint 联合检索表示。  
**Method thesis**：只在 tail9/tail10 后交换 role-adapter delta，并由后续 frozen
CLIP tail 解释；用同一增强 tensor 上 state-clean no-exchange retrieval regret
训练通信。  
**Date**：2026-09-02

## Claim Map

| Claim | Minimum convincing evidence | Blocks |
|---|---|---|
| C1：CRDE 在完整路径身份隔离下产生真实协同收益 | 三折 fused 不劣、weighted gain≥1 mAP、identity-bootstrap LB>0、三 receiver aggregate均改善 | B1, B2 |
| C2：确定性三专家协同解决当前 deployment bottleneck | 唯一 D1 fused≥65且严格胜 exact Signal/no-exchange/C/T/M | B3 |
| Anti-claim：增益来自状态污染、不同增强或分类头 | off无head/无state mutation；on/off同tensor；评价pre-BN | B1 |

## Paper Storyline

- 主成功前只运行 engineering contracts、complete-path OOF qualification 和条件
  D1 main；不运行消融、多seed、official或reranking。
- Q1 只回答 mechanism transfer，不替代 D1。
- 只有 D1 通过后，才规划 no-exchange/full-state/without-regret 三项最小消融；
  它们不属于当前执行队列。

## Experiment Blocks

### B1 — M0 Counterfactual Integrity

- **Claim**：CRDE on/off 是真正 matched、无状态污染的可训练接缝。
- **Setup**：synthetic CPU tests + remote real Signal/V8 preflight；seed42。
- **Checks**：两层同步无self；step0 exact；on/off同tensor data pointer；off调用
  V15 head计数0；frozen parameter/buffer与BN stats SHA不变；pre-BN evaluator；
  exact Signal prefix；`REGRET_WEIGHT==1.0`；两 exchange live gradients。
- **Success**：所有合同测试通过；任何一项失败则不运行训练。
- **Priority**：MUST-RUN。

### B2 — Q1 Complete-Path Identity-OOF Qualification

- **Claim**：CRDE 相对同一 fold、同一 checkpoint SHA 的 no-exchange base，在未见
  identity 上提高 fused 与三个 receiver。
- **Data**：V12 frozen fold registry；每折94 source/47 heldout identities；合计
  21 cross-camera identities、571 queries；dev0/official0。
- **Training**：每折只训练 CRDE+source-local heads，B64/K8，20 epochs，final
  only，seed42；base frozen/eval。
- **Comparators**：同一 fold exact no-exchange fused/C/T/M；绝不使用 all-fit V8
  作为 Q1 comparator。
- **Metrics**：per-fold/weighted mAP、Rank-1；matched branch gains；21-identity
  bootstrap 10,000 resamples；frozen SHA/access/runtime/memory。
- **Success gate**：
  1. 每折 fused mAP gain `>=0`；
  2. weighted fused gain `>=1.0 mAP`；
  3. fused gain bootstrap 95% LB `>0`；
  4. aggregate CNN/T/M gain 各 `>0`；
  5. 每折至少两个 receiver gain `>0`；
  6. aggregate fused 严格高于三个 CRDE branches；
  7. integrity/access contracts 全过。
- **Failure interpretation**：该固定 CRDE 不能稳定转化 V12 complementarity；
  封存 V15，不运行 D1。
- **Priority**：MUST-RUN。

### B3 — D1 Sole Deployable Main

- **Authorization**：只在 B2 全门通过后。
- **Data**：固定141-fit训练、30-dev只评价一次；official0。
- **Training**：加载 V8 all-fit Phase-A，base frozen；相同 CRDE/loss；seed42；
  B64/K8；20 epochs；final checkpoint only，不用dev选点。
- **Outputs**：exact Signal、frozen no-exchange V8 bank、CRDE fused/C/T/M。
- **Success**：fused mAP `>=65`；严格高于全部 comparator；Rank-1严格高于
  CRDE C/T/M；checkpoint strict reload parity；official0。
- **Failure interpretation**：V15 不解决部署门；封存且保留 V8 Phase-B 58.4050
  为当前最好。
- **Priority**：CONDITIONAL MUST-RUN。

## Run Order and Milestones

| Milestone | Run ID | Action | Go/Stop gate | Cost |
|---|---|---|---|---:|
| M0a | V15-M0-TDD | public seams RED→GREEN | all focused tests green | 10–15 min |
