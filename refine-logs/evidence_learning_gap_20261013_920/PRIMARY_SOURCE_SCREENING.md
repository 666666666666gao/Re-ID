# External mechanism screening: the evidence-learning gap

This is source research, not a new experiment. The original six runs and fixed-best diagnosis remain closed. Neither method below is an implementation-ready solution or evidence of expected ReID gains.

**ACoL: retain one formation precedent.** In [the author VGG code](https://github.com/xiaomengyc/ACoL/blob/8b59d007205d698b868be58a46cb9469883f69fc/models/vgg/vgg_v1.py#L56-L81), branch A supplies a normalized class map; `erase_feature_maps` removes selected spatial features before B receives them. Both branches use classification loss. The mechanism changes B's input evidence rather than merely reweighting its final score. It does not freeze an existing global model or guarantee that B cannot recover the same semantic cue elsewhere. The inference-time predicted-label substitution is commented out.

The [released validation path](https://github.com/xiaomengyc/ACoL/blob/8b59d007205d698b868be58a46cb9469883f69fc/exper/val_frame.py#L107-L139) passes dataset labels into the model for masking. Classification is measured from A; the localization map uses both branches. This is an object-localization reference, not a validated label-free extractor for unseen ReID identities. A training-only adaptation would be different from this release. See the [original CVPR2018 paper](https://opus.lib.uts.edu.au/bitstream/10453/131482/1/Zhang_Adversarial_Complementary_Learning_CVPR_2018_paper.pdf).

**RSC: useful comparison, not a fixed-global supplement.** The [official ResNet](https://github.com/DeLightCMU/RSC/blob/bf6d280c5d74910f009ea8963c59167252659666/Domain_Generalization/models/resnet.py#L70-L154) derives spatial or channel masking from its own true-class sensitivity, retains masking on selected affected samples, and trains that same model. It includes extra head evaluations and a saliency backward. It does not condition a second learner on evidence already used by a separate fixed global model. The [trainer](https://github.com/DeLightCMU/RSC/blob/bf6d280c5d74910f009ea8963c59167252659666/Domain_Generalization/train.py#L86-L120) concatenates flips during training and disables masking via its positional `False` argument during testing. See the [original ECCV2020 paper](https://www.ecva.net/papers/eccv_2020/papers_ECCV/papers/123470120.pdf).

**Project consequence, a hypothesis:** a useful adaptation would change which evidence a supplementary learner can reuse, before evidence formation, while preserving the existing global task. It would need a real mapping from global identity decisions to the affected input, coverage of bypass paths, a same-budget random/ordinary-mask control, and net same-model retrieval gains on unseen identities. Spatial exclusion, sharper masks, lower source loss and stronger standalone branches do not establish that result. No such mapping or trained adaptation was implemented here; existing repair/keep and responsibility objectives remain prior controls.
