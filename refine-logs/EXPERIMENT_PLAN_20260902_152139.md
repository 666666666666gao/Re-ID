# TriFusion V16 SATR Experiment Plan

**Problem**：把 CNN/Transformer/Mamba 已证实的 query-level 互补转成跨身份可
泛化、无需 Router/hidden exchange 的部署增益。  
**Method Thesis**：只修复 exact Signal-hard relation 上由另外两支共同确认的
receiver margin 缺口，推理时删除全部协同路径。  
**Date**：2026-09-02

## Claim Map

| Claim | Why It Matters | Minimum Convincing Evidence | Linked Blocks |
|---|---|---|---|
| C1：SATR 产生 identity-disjoint、可归因的三方互促 | V8 Oracle 有互补但 V8–V14 Router、V15 hidden exchange 均失败 | 三折 SATR 对 matched no-SATR：聚合 fused≥+1 mAP、bootstrap LB>0、三分支聚合全正、每折至少两支正 | B1, B2 |
| C2：训练期协同转化为零新增推理模块的部署增益 | 论文不能只报告 fit-only mechanism score | 唯一 seed42 D1 fused≥65，严格胜过 exact Signal、V8 Phase-B 和 V16 三支 | B3 |
| Anti-claim：增益只是额外 fine-tuning 或随机数据顺序 | SATR/no-SATR 若预算不同就无法归因 | 同初态、同 trainable scope、同 sampler/augmentation/20 epoch，仅 relation loss 不同；paired hashes 全等 | B1, B2 |
| Anti-claim：增益来自更多推理参数或动态选择 | 用户目标是三专家协同，不是再堆 Router | 新 trainable module=0；inference graph 与 fixed V8 bank 相同 | B3 |

## Paper Storyline

- **Main paper must prove**：SATR 的三折 matched Q1 机制增益；唯一 D1 达到冻结
  门后，给出 exact Signal、V8 Phase-B、fused 和三分支主表。
- **Success 后 appendix 才允许**：single-peer、无 protect、无 SATR 三项最小
  deletion/isolation；official-test 固定一次；错误关系与 coverage 变化图。
- **Intentionally cut before success**：多 seed、baseline rerun、Router/alpha
  扫描、V15 edge/epoch/LR 调参、DINO/text、reranking、official test、第二数据集。
- **Frontier block**：不单独增加。exact Signal/CLIP relation anchor 已内生于
  SATR；没有额外 LLM/VLM/Diffusion/RL 主张需要证明。

## Experiment Blocks

### Block 1：M0 可执行性与公平性资格门

- **Claim tested**：SATR 数学、数据语义、优化路径和 paired comparator 合同可
  在真实 B64/K8 上执行，且不改 exact Signal。
- **Why**：防止把 dead loss、camera 混淆、随机 draw 不同或额外训练参数误当
  机制效果。
- **Dataset/split**：RGBNT201 141-fit 内部 V12 三折；只用 source-training
  records，dev0/official0。
- **Systems**：V16 initial SATR endpoint；matched no-SATR endpoint 只用于初态/
  draw/hash 对齐，不产生性能结论。
- **Metrics/gates**：
  - pure-function RED→GREEN：physical-camera positive、nearest negative、empty
    query exclusion、two-peer mask、teacher detach、live receiver gradient、空 mask
    exact zero、protect one-sided；
  - exact baseline tensor parity 与 frozen Signal SHA；
  - threshold evidence file SHA 绑定；
  - 三折前8个 deterministic B64 batches 的 CNN/T/M fixed-initial coverage 均在
    `[0.5%,25%]`；
  - SATR/no-SATR initial state、trainable-name、sample-order/sampler-index、seed
    contract 和前8 batch post-transform RGB/NIR/TIR tensor SHA 全等；
  - 真实 B64/K8 SATR 8-step：0 overflow，全部应训练 tensors 至少一次非零有限
    梯度；
  - 100-step fixed-batch loss 下降并满足与既有 V15 同类的 conservative floor
    excess ratio `<=0.1`；
  - peak reserved <24 GiB；dev0/official0。
- **Failure interpretation**：工程/合同未成立；只修实现，不运行 Q1，不改科学
  阈值。
- **Target**：实验完整性表 / appendix；M0 receipt。
- **Priority**：MUST-RUN。

### Block 2：Q1 Complete-path Matched Relation Qualification

- **Claim tested**：SATR 本身能在 unseen identities 上产生稳定三方互促。
- **Why**：这是 V16 唯一主机制的科学资格门，也是访问30-dev前的 fail-closed
  屏障。
- **Dataset/split**：V12 三个 identity folds；每 fold 94 source IDs 训练、47
  heldout IDs 评价；总 heldout eligible query 571；dev0/official0。
- **Compared systems**：每 fold 从逐 tensor 同初态训练：
  1. SATR；
  2. matched no-SATR (`lambda_r=lambda_p=0`)。
- **Setup**：seed42；B64/K8；20 epochs；AdamW LR `3.5e-4`、WD `1e-4`；AMP
  init256；两端点开放相同 role adapters/residual projections/necks/classifiers；
  Signal/shared CLIP tail冻结；final epoch only；每端点前重置 RNG/loader。
- **Decisive metrics**：fused/CNN/T/M 的每折和聚合 mAP、Rank-1；query-level
  paired AP gain；21-identity cluster bootstrap 10,000 resamples seed42；coverage
  训练轨迹仅诊断。
- **Success criterion**：
  - 三折 fused SATR-minus-noSATR mAP 均 `>=0`；
  - query-weighted aggregate fused gain `>=+1.0 mAP`；
  - fused identity-bootstrap 95% lower bound `>0`；
  - aggregate CNN/T/M gains 全 `>0`；
  - 每 fold 至少两支 branch gain `>0`；
  - SATR fused mAP 严格高于 SATR CNN/T/M；
  - paired integrity、fold isolation、final-only、frozen state、dev0/official0 全
    PASS。
- **Failure interpretation**：SATR 未证明跨身份互促；封存 V16，不访问 dev，
  不扫描阈值/epoch/LR/loss weight。
- **Target**：主机制表（若成功）；否则负结果与 postmortem 记录。
- **Priority**：MUST-RUN。

### Block 3：D1 唯一 All-fit Main Result（条件执行）

- **Claim tested**：SATR training-only collaboration 能形成部署增益并达到主门。
- **Authorization**：仅 B2 所有门通过。
- **Dataset/split**：固定141-fit/30-dev；训练期间 dev0；final checkpoint 一次
  frozen dev；official0。
- **Compared systems**：同 checkpoint 输出 exact baseline_only、SATR fused、
  CNN、Transformer、Mamba；另列已封存 V8 Phase-B `58.4050/59.3939` 作为
  deployable comparator，不重跑。
- **Setup**：从 V8 Phase-A all-fit checkpoint；seed42；B64/K8；同一 SATR
  constants/optimizer scope；20 epochs；final-only；无 checkpoint selection。
- **Success criterion**：fused `>=65 mAP`；mAP 严格高于 exact Signal、V8
  Phase-B、CNN/T/M；Rank-1 严格高于 CNN/T/M；checkpoint strict reload 一致；
  frozen Signal SHA unchanged；official0。
- **Failure interpretation**：方法未达到部署/论文门；封存 V16，不做 official、
  消融或多 seed。
- **Target**：主结果表。
- **Priority**：MUST-RUN IF AUTHORIZED。

### Block 4：成功后最小创新隔离（当前 CUT/LOCKED）

- **Claim tested**：two-peer/Signal intersection，而非普通继续训练或单 peer，
  是主要增益来源；protect 只负责安全。
- **Authorization**：B3 全门通过后才解锁。
- **Minimal variants**：matched no-SATR、single-best-peer 替代 intersection、
  `lambda_p=0`。不扫描连续超参。
- **Metrics**：同固定 dev mAP/Rank-1、三分支、coverage/unique wins。
- **Priority**：LOCKED UNTIL MAIN SUCCESS。

### Block 5：成功后 official test 与 SOTA 表（当前 CUT/LOCKED）

- **Authorization**：B3 成功且配置/checkpoint完全冻结。
- **Protocol**：全部171训练身份重训、固定 endpoint，官方 test 只评估一次；同
  协议、同预训练、无文本/mask/TTT/rerank赛道单列。
- **Claim gate**：只有真实结果达到或超过公开同赛道最佳才使用 SOTA；否则按
  实际名次/差距报告。
- **Priority**：LOCKED UNTIL MAIN SUCCESS。

## Compute and Data Budget

- **Before D1 authorization**：约 `1.5–2.0 GPU-hours`；
- **Including conditional D1**：约 `2.0–2.5 GPU-hours`；
- **GPU**：远端单 RTX3090 24GB；本地只做代码、测试和 SSH 传输；
- **Data**：现有 RGBNT201 与 V8/V12 checkpoints；不下载新数据；
- **Human evaluation**：无；
- **Biggest bottleneck**：SATR eligible relation 稀疏，且 branch repair 未必在
  fixed concatenation 中转成 fused mAP。

## Risks and Mitigations

- **Paired augmentation 不一致**：两个 endpoint 前重置 seed/worker loader，并
  用前8 batch tensor SHA fail-closed；不添加兼容 fallback。
- **physical camera 被 SIE label 混淆**：public unit test 使用人工 PID/camera；
  runner receipt 同时记录 raw camera IDs 与 model camera labels。
- **SATR mask 为空**：初态 activity gate fail-closed；训练 batch 空 mask 精确0；
  不切 single peer。
- **coverage 后期下降**：只作为修复进程诊断，不作为失败门。
- **Q1 正但 D1 负**：如实说明 fit-only mechanism 没转成部署增益，封存，不
  解锁 ablation/official。
