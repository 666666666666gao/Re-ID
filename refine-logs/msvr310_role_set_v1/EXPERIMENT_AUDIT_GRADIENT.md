## B. Metric/score normalization — PASS

This is a loss/gradient consistency check; it reports no AP, mAP, Rank-1, or retrieval accuracy. Distances are unsquared Euclidean distances after L2 embedding normalization (`repo/tools/msvr_role_set_relations.py:60-64`). Gradient comparison reports both raw norms, raw difference norm and cosine (`repo/tools/probe_msvr_history_candidate_gradients.py:53-66`). The relative direct/VJP error is the difference norm divided by the larger raw gradient norm, with a fixed 0.005 tolerance (`repo/tools/probe_msvr_role_set_gradients.py:128-133`). These are explicit numerical-comparison definitions, not a prediction score divided by its own maximum to manufacture accuracy near one.

For each current anchor, let `p` be its original maximum valid positive distance, `n` its original minimum negative distance across current/history, `a` the first fused negative position, and `U` the deduplicated fused/CNN/Transformer/Mamba negative positions. The implementation computes:

`hard = relu(p - n + 0.3)`

`candidate = [hard + sum(relu(p - d_j + 0.3) for j in U excluding a)] / |U|`

and then averages over the 64 anchors (`repo/tools/msvr_role_set_relations.py:25-56`). Deduplication is by candidate position; different current views of a repeated sampled record remain separate positions. History instead holds each record's latest view and excludes records present in the current batch (`repo/tools/msvr_instance_memory.py:15-37`). The original current/history `torch.maximum`/`torch.minimum` hard term is retained so ties retain the prior hard-term derivative; the fused first-position index is used only to avoid counting that hard term twice.

The count denominator is an intentional loss-definition change. It necessarily weakens the weight of the most extreme relation and makes this candidate loss no greater than the hardest loss. The plan and current report acknowledge that this intervention cannot by itself distinguish role coverage from ordinary objective softening (`repo/refine-logs/msvr310_role_set_v1/EXPERIMENT_PLAN.md:7-11`, `repo/results/MSVR310_ROLE_SET_GRADIENT_CHECK_2026-09-08.md:27`). I verified the inequality on all 24 recorded batches. This is not hidden score normalization.
