# 研究方案：V14 Fold-Robust Retrieval-Regret Router

## Problem Anchor

- **底线问题**：在远端单张 RTX 3090 上，基于 RGBNT201 固定
  `141-fit / 30-dev`、seed 42 和 exact Signal 3072D 前缀，让 CNN、
  Transformer、Mamba 三类预训练残差专家形成可部署的动态融合，而不是
  继续被近静态 Router 平均。
- **必须解决的瓶颈**：V8 已证明专家具有 query 级互补性；V13 的九路
  点式 utility-KL 目标却近乎均匀且随 fold 漂移，不能稳定把互补性转成
  held-out 检索增益。
- **非目标**：本阶段不增加新 backbone、不启用 HFER、不复现 baseline、
  不做多种子、不做消融、不访问 official test，也不扫描温度、epoch、LR、
  margin、fold 或损失权重。
- **成功条件**：先通过严格 train-only OOF Router 门；只有通过后才允许
  一次 dev。dev fused 必须 mAP≥65，且 mAP/Rank-1 严格超过 exact Signal、
  当前可部署最好结果和 CNN/Transformer/Mamba 三个分支。

## 证据锚点

V13 target-learnability 诊断使用 571 个 fit-only query、21 个身份和三折，
训练为 false、optimizer step 为 0、dev/official access 均为 0。关键结果是：

- 九路 target 平均归一化熵 `0.99983197`；
- 平均最大概率 `0.11527554`，均匀值为 `0.11111111`；
- Top1-Top2 utility 中位差仅 `0.00034070`；
- fold 槽位排序相关为 `-0.50 / 0.40 / 0.05`；
- identity 多数赢家准确率仅 `49.91%`；
- residual norm 对 utility 的最大绝对相关仅 `0.11382`。

这些证据只支持删除点式 utility-KL，不支持预言 V14 能达到 65 mAP。

## 方法假设

> 当专家、部署输入、融合能量和质量控制全部固定时，在每个 OOF teacher
> 坐标系内直接优化跨相机检索 regret，并由最坏 source fold 控制更新，会比
> V13 的近均匀点式动作蒸馏更稳定地迁移到 held-out fit fold。

V14 是一次 train-only 可证伪实验；在 dev 成功前不是论文贡献结论。

## 冻结结构与范围边界

保持不变：

- 三模态共享 flip、padding、crop，几何对齐后才独立 RandomErasing；
- exact frozen Signal 3072D baseline prefix；
- V8 Phase-A pretrained-tail CNN、Transformer、Mamba residual experts；
- matched-token residual；
- `P(modality|x) × P(expert|modality,x)` 层级 Router；
- 缺失模态质量严格为零；
- exact-prefix blockwise fusion，固定有界 `alpha=0.2`；
- V13 Router hidden width、LR、weight decay、100 epochs/fold 和质量损失
  权重 1.0。

Router 输入是冻结的 **all-fit deployment features**；只有 teacher/replay
baseline 与 residual embedding 是 identity-OOF。V14 因而是
“deployment-input / OOF-teacher train-only qualification”，不是完整特征
路径的 identity-OOF 泛化实验。该边界必须进入 M0、Q0、Q1 回执。

## Fold-bound 检索风险

所有检索损失必须通过下列语义接口计算：

```text
risk(fold_id, rows_in_fold_id, features_from_generator_fold_id, weights)
```

接口要求 row、fold 和 OOF generator 完全一致；query/gallery 只来自同一
fold；不允许跨 generator 计算距离。embedding 通过 exact V13 fusion 组成并
L2 normalize。对 query `i`：

```text
d_pos(i) = max_j ||z_i-z_j||_2,
                 y_j=y_i 且 camera_j!=camera_i
d_neg(i) = min_k ||z_i-z_k||_2, y_k!=y_i
R_f(w)   = mean_i softplus(d_pos(i)-d_neg(i)).
```

不增加 margin、temperature、listwise relaxation 或新损失权重。

## Source-only 固定策略与最坏 fold regret

当 Q1 留出 fold `h` 时，source folds 为 `a,b`。只用 source 检索风险选择
一个共同的固定槽：

```text
s* = argmin_s max(R_a(one_hot(s)), R_b(one_hot(s))), s∈{0,...,8}.
```

九槽枚举是 comparator 的定义，不是超参数搜索；它不能读取 `h`。定义：

```text
G_f(w)      = R_f(w) - stop_gradient(R_f(one_hot(s*)))
L_identity  = max(G_a(w), G_b(w))
L_total     = L_identity + L_quality.
```

V13 `teacher_identity_utility`、utility softmax、temperature 和 KL 全部退出
优化，只保留为只读诊断。

## Q1 对齐门禁

在 held-out fold `h` 上，将 Router 与 source-only `s*` 应用于同一套
fold-bound OOF teacher embedding。定义正向增益：

```text
risk_gain_h   = R_h(one_hot(s*)) - R_h(learned)
ap_gain_h     = AP_h(learned) - AP_h(fixed)
margin_gain_h = margin_h(learned) - margin_h(fixed).
```

必须同时满足：

1. 三个 fold 各自 `risk_gain_h > 0`；
2. 三个 fold 各自 `ap_gain_h >= 0` 且 `margin_gain_h >= 0`；
3. pooled paired risk/AP/margin gain 的 identity-cluster bootstrap 95% 下界
   全部严格大于 0；
4. RGB、NI、TI 人工退化后各自模态质量下降；
5. 缺失模态最大质量严格为 0；
6. Phase-A 所有 tensor SHA 不变；
7. dev/official access 均为 0。

Replay Rank-1、V13 expected utility 和 action-winner Top-1 只报告、不门控。
held-out fold 自身最佳固定槽的 risk/AP/margin 也仅作为 oracle diagnostic，
绝不参与 `s*` 选择、训练或 Q1 判定。

## 执行顺序

### M0：public-seam tests

- toy risk 与手算一致；
- same-camera positive 被排除；
- 错误 fold/row/generator 绑定被拒绝；
- Q1 与 final-refit 路径均禁止跨 fold 距离；
- 每个 Router 参数张量均获得有限非零梯度；
- missing mass、exact prefix、fixed alpha 保持原合同；
- 回执明确记录 all-fit Router input / OOF teacher 范围。

### Q0：real-cache zero-step gate

在 exact paired cache 上分别计算三折 uniform 与九个 fixed-slot risk，验证
正负样本支持、loss/gradient 有限、全部 Router 参数有梯度、Phase-A SHA
不变、optimizer step=0、dev0、official0。Q0 只验证信号可执行，不声称增益。

### Q1：唯一 seed-42 OOF qualification

每次留出一折，仅用另两折选 `s*` 并训练 100 epochs；应用上述检索与安全
门。任一门失败即封存 V14，不做任何扫描，不 final refit，不访问 dev。

### 条件 final refit 与一次 dev

仅在 Q1 全通过后，使用：

```text
s_all = argmin_s max_f R_f(one_hot(s))
max_f [R_f(w)-stop_gradient(R_f(one_hot(s_all)))] + L_quality
```

进行一次 all-fit Router refit。三个 `R_f` 始终在各自 OOF generator 内计算；
只比较标量 regret，不混合 feature vector 或距离。保存一个 Phase-A+Router
checkpoint，再执行一次固定 dev。

## 失败解释与 claim ceiling

以下任一情况即否定 V14 固定假设：Q0 梯度无效；任一 held-out fold risk
无正增益；AP 或 margin 下降；任一 bootstrap 下界不为正；质量、缺失模态、
SHA 或访问边界失败。

Q1 通过最多只支持：该固定目标在 all-fit deployment input、identity-OOF
teacher/replay 指标下跨三个登记 fit folds 迁移。它不证明完整路径 OOF 泛化、
HFER 协作、dev 提升、SOTA、因果校准或广泛鲁棒性。只有条件 dev 主门通过，
才可声称可部署增益；HFER 和最终三个论文创新仍需后续主实验支持。
