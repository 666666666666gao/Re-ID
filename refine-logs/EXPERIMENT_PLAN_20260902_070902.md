# TriFusion V12 完整路径 Identity-OOF Utility Teacher 实验计划

**Problem**：V8/V11 的专家 Adapter 虽按身份 OOF 训练，但底层 Signal token field 来自在全部 141-fit 身份上训练的 checkpoint，held-out residual 达到 100 mAP，Router 教师目标因此含身份泄漏并饱和。

**Method Thesis**：固定三折身份划分；每折从同一 raw CLIP 初始化开始，仅在另外两折身份上训练一个不做验证选择的 Signal 内部教师，再在同一 fit 子集训练 CNN/Transformer/Mamba 专家；只在完整路径从未见过的 held-out 身份上生成 residual 与 `expert×modality` identity-margin 目标。最终部署仍使用既有 all-fit V8 Phase-A 专家，只替换 Router 的 OOF 教师监督。

**Date**：2026-09-02

## Claim Map

| Claim | Why It Matters | Minimum Convincing Evidence | Linked Blocks |
|---|---|---|---|
| C1：完整路径 OOF 能产生非饱和且多样的专家/模态身份效用 | 当前 Router 监督的根本缺陷是 all-fit Signal 泄漏；不先修复监督，继续改 Router 没有意义 | 3 折、571 query；每折 Signal+专家训练身份与 held-out 身份交集为 0；所有 fixed residual 输出 mAP<99；CNN/Transformer/Mamba 与 RGB/NI/TI 均有独有 margin 胜例；residual expert Oracle 比最强固定专家至少高 1.0 mAP | V12-Q0 |
| C2：由完整路径 OOF 监督的层级 Router 能把互补性转成可部署增益 | V8 Oracle 高而 learned Router 弱，必须证明监督修复能改善 learned routing | train-only Router OOF expected margin 严格高于固定槽，Top-1 严格高于多数槽；缺失模态质量为 0，三种受损模态质量均下降；随后唯一 dev 上 fused≥65 且严格超过 Signal、V8 Phase-B 和三个分支 | V12-Q1、V12-R001 |

## Paper Storyline

- 主张候选：**Complete-Path Identity-OOF Utility Supervision** 修复多专家路由中的隐藏特征泄漏。
- 支撑机制：共享几何、matched-token heterogeneous residual experts、层级 `P(m|x)P(e|m,x)` 与有界 `alpha(x)` 均保持不变，避免把多项结构同时改动。
- 三个论文机制仍仅为候选：完整路径 OOF 效用监督、异构预训练尾部专家形成、质量感知层级有界融合。只有主结果通过后才进入消融。
- 明确删除：DINO 扫描、Signal baseline 重跑、fold 教师 dev/test 评价、超参数/epoch/阈值扫描、多 seed、HFER、official test 和运行时 fallback。

## Experiment Blocks

### Block 1：V12-Q0 公共接缝 TDD 与真实单步 preflight

- Claim tested：CLI/JSON receipt 能证明每折完整路径隔离，且 fail-closed 门不会把饱和结果晋级。
- Dataset / split / task：RGBNT201 141-fit 内部三折；preflight 只用 fold0 fit 的一个真实 B64/K8 batch；dev/official=0。
- Public seams：`build_complete_path_fold_records`、`evaluate_complete_path_oof_gate`、CLI `--mode preflight|oof` 与 JSON receipt。
- Success criterion：RED→GREEN；worked example 证明 relabel 后 fit/held-out 交集为 0；饱和或缺任一专家/模态胜例时 gate=false；真实单步 Signal optimizer finite、B64/K8、heldout batch 未读取、GPU 峰值受 24 GiB 容量约束。
- Failure interpretation：工程路径不可信，禁止完整三折。
- Priority：MUST-RUN。

### Block 2：V12-Q0 完整路径三折 OOF 目标生成

- Claim tested：C1。
- Dataset / split / task：现有固定 141-fit 身份；三折 deterministic identity split；仅 21 个 cross-camera eligible 身份形成 571 个 query；所有检索距离严格在本折 held-out query/gallery 内计算。
- Setup details：seed42；每折 Signal 从固定 `ViT-B-16.pt` raw CLIP 初始化，在约 94 个 fit 身份上训练固定 50 epoch；共享三模态几何；不做验证和 checkpoint selection，只用 final epoch；同折 V8 专家固定训练 20 epoch；B64/K8；AMP；不访问 30-dev/official。
- Outputs：每折 Signal final SHA、专家 checkpoint SHA、fit/heldout identity registry、optimizer/overflow/显存、residual CNN/T/M/bank mAP/Rank-1、slot identity margins、571-query cache 与访问计数。
- Qualification gate（全部满足）：
  1. 3 折且合计 571 queries；每折 Signal fit IDs、expert fit IDs 与 heldout IDs 交集均为 0；
  2. raw CLIP SHA 固定；Signal final-only 50 epoch、专家 20 epoch；无 heldout checkpoint selection；
  3. 所有 fixed residual 输出 mAP `<99`；
  4. CNN/Transformer/Mamba 与 RGB/NI/TI 各至少一个独有 slot-margin 胜例；
  5. residual expert hard Oracle 至少比最强固定 expert 高 `1.0 mAP`，slot Oracle mean margin 严格高于最强 fixed slot；
  6. finite、零 AMP overflow、dev access=0、official access=0。
- Failure action：封存 V12；不改 fold、epoch、LR、margin、门槛或专家结构，不训练 Router、不访问 dev。
- Cost：RTX3090 约 90–120 分钟；只运行一个 seed42 配置。
- Priority：MUST-RUN。

### Block 3：V12-Q1 条件式 Router 与唯一 dev

- Claim tested：C2。
- Entry gate：V12-Q0 全门通过。
- Router：复用既有 all-fit V8 Phase-A checkpoint、同一层级 Router/质量退化/alpha 配置；只把教师 cache 换成 V12 complete-path OOF margin cache；不改 LR、epoch 或 alpha。
- Train-only gate：learned OOF margin 严格高于 fixed；Top-1 严格高于 majority；RGB/NI/TI corruption mass 均下降；missing mass=0；dev/official=0。
- Dev gate：Q1 通过后只访问一次冻结 30-dev；fused mAP≥65，并严格超过 exact Signal 58.0109、V8 Phase-B 58.4050 及 CNN/Transformer/Mamba；official=0。
- Failure action：任一门失败即封存，不做扫描、消融、多 seed 或 official。
- Priority：CONDITIONAL MUST-RUN。
