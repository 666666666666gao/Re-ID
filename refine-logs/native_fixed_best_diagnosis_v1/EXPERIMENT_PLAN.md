# 固定 best 的 global／角色修正诊断

2026-10-04。原 V6 九端及原一次性 CPU 报告已经完成；native−semantic 的预登记推进条件为 0/3。新训练、第二／第三模块暂不启动，先完成以下唯一诊断。

## 固定输入与问题

只读取 `logs/native_research_v6_20261003_794/accepted_matrix.json` 中三个数据集的 semantic、native 六份正式 mAP-best。每份沿用原初始化见证、原 V6 构造／严格加载、原两卡分段、完整 query/gallery、原 camera/scene 过滤及作者交叉计分。独立 global-only 的原正式距离为参照，不重新推理它。九份正式 best、公开 CLIP、初始化、协议、训练／评价回执以及原 314 项执行源码均绑定 SHA。

1. 同权重 `L2(g)` 与 `f=L2(g+gain*c)`：实际角色修正对该模型检索的作用。
2. 同权重 `L2(g)` 与独立 global-only：角色系统训练后，其 global 与独立训练参照的差别。
3. 实际 gain、逐样本 `||gain*c||/||g||`、方向变化，以及 native 读取出口的真实幅度。

前两项的 mAP 差可作算术分账，但不能当作因果梯度归因。同模型 global 不是独立 global-only 消融。附带 `L2(c)` 是描述性诊断，不用它证明互补或重选方法。

## 执行合同

- 三数据集各 semantic、native，共六端，独立子进程顺序执行；仅 2026 物理 GPU0/1，一组两卡，不使用 2025 计算。
- 原始 `forward_features` 对每个记录只调用一次，取出 g/c/h/f。使用原 eval loader、FP32 推理行为；不重新执行注意力，不修改模型 forward。
- native hook 只观察实际 `detail_reader` 输出和 CNN 第一输出 LayerNorm 的输入。报告 detail／(该输入−detail) 的范数比；分母含原语义与 anchor，是推导量，不能称为额外一次独立语义读取。
- 全程 eval＋inference_mode，零 optimizer 更新，参数／buffer 前后 SHA 相同且没有梯度。原 formal receipt、距离、best、初始化及源码前后不变。
- f 的正式四项计分必须复现原回执（固定 1e−5 个百分点），计分还与作者函数交叉验证。原距离的最大差单独记录，不把逐位差直接当作指标失败。
- 如失败，保存原失败和日志，不重试挑一次通过，不修改阈值、权重、增益、batch、精度、环境或 epoch。新诊断另存目录，不调用已经退役 M0 二进制依赖的旧 verifier，不覆盖原报告。
- query/gallery 的四类特征、逐样本诊断与三类距离只留远端；同步代码、计划、JSON／文本摘要及 SHA。每端均保留全部 query 的 AP／首正例排序、身份均值、首位修复／新增错误。
- 不查询、限制或监控功率与温度；不重建环境或引入新的工程一致性门。启动只核对可用 GPU、原依赖和磁盘。
- 预计六端约 8–12 分钟；按 180–300 秒或预计里程碑查看。观察超时不能触发重启。

## 结论与后续边界

若同模型修正有效而总模型落后，优先研究 global 的共同训练变化；若修正本身破坏排序，优先研究读出的内容／作用。仅有幅度或局部独立分数不能证明任何一种原因。完成后基于全部六端，登记唯一下一训练假设，保持作者配方和匹配参照，不能自动叠加 N2/N3 或按已消费官方分数扫描参数。

本诊断不改变原 50 轮、best 选择、旧 parity FAIL 或成功 M0 退役记录；不是新训练种子、无偏测试或 SOTA 证据。完整科学 Goal 仍 active／unmet。
