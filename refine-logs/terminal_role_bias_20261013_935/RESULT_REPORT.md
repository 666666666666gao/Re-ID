# 共同修正是否有真实可达参数路径？末层bias核查

**源码与实际封存参数支持一个128维末层bias路径，但当前已学bias直接贡献极小，不能解释观察到的大共同correction。**这项结果收紧§934的参数可达性边界，也阻止把一个数学对称性直接改写成“删掉bias就能修复检索”。没有新增训练或检索成绩。

## 1. 可达的是哪一个子空间

实际继承链为`GlobalConditionedEvidence → DetachedSemanticTriFusion`，角色使用`ExcludedPatchRoles → GlobalTokenRoles`。最终Mamba传播结果经`output_norms[2]`的LayerNorm，再进入`RoleEvidence.mamba`和结构化线性读出。末层128维bias位于CNN/T桥接和Mamba传播之后，不反馈给上述路径。

保持所有其他参数、global、gain及同一次输入/随机状态不变，改变这一参数 \(\beta_M\mapsto\beta_M+\delta\beta\)，则每个模态、槽位都增加相同的128维 \(\delta\beta\)。区域均值后仍相同，最终：

\[
\Delta c_{m,r}=W^M_{m,r}\delta\beta,\qquad
\Delta h=\gamma A\delta\beta,
\quad A\in\mathbb R^{1536\times128}.
\]

其中A仅取实际读出中Mamba对应的128输入列。bias-free读出并不消除前面LayerNorm已有的加法参数。当前源码默认使用有可学习affine的LayerNorm；其定义和默认bias参见[PyTorch官方文档](https://docs.pytorch.org/docs/2.14/generated/torch.nn.LayerNorm.html)。文档版本不是本项目运行版本的证明，本次运行Torch版本保留在RESULT.json。

结合§934已核实的train-BN CE＋raw Triplet，两项角色任务在理想实数计算中对该共同平移不变；global任务不依赖这个末层角色bias。训练期exposure来自global关系，也不依赖末层bias。因此这里不再只是任意输出向量的自由设想，而是一个具体模型参数子空间。**它仅是任务项的条件性平坦方向；Adam参数weight decay、浮点误差及优化器状态均不能因此忽略。**本次没有重建训练模型/optimizer或计算实际训练梯度，不能推断该bias历史更新的原因。

CNN或Transformer的bias还会经桥接改变下游内容，不能把本结论复制到它们的整条作用路径。更不能声称所有1536维平移、当前全部common correction或其他角色参数都属于这个子空间。

## 4. 对下一步的实际约束

1. §934的任务几何问题有一条真实末层参数路径，故“最终readout没有bias”不能用来否定这一问题；但这里只验证了128维子空间。
2. 当前末层bias的直接c范数仅为common c范数的约0.00092%／0.00110%。它不足以解释此前94.09%／82.59%的common能量幅度；不把这两个不同分母的指标相减，也不把剩余部分称为噪声。
3. 因而不根据该理论结论直接删除LayerNorm bias、中心化或改一套head。若后续恢复方法研究，仍须证明监督作用于实际融合比较并产生净收益；已有joint-L2与repair/keep等负／混合结果不被推翻。
4. 当前新增证据的用途、重复性和新增损伤仍未解决。本项不证明压缩、背景、错位或数值误差是唯一原因，不升级新模块／教师或宣称超过Signal。
