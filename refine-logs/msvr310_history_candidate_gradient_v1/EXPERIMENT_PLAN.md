# 固定来源模型的历史候选梯度贡献诊断 V1

登记日期2026-09-08；依据98828b7完整新鲜坐标Q1及审计。该版本两组五门0/5，保持封存。本项是来源机制测量，不是新的训练方法、Q1或主结果前模块消融；只用seed42。

## 唯一问题

当前实例记忆扩展了困难关系；全新鲜坐标改善若干来源优化指标但未证明heldout收益。历史候选仍detach，尚未测量其候选侧参数梯度。在同一固定模型/相同当前64个anchor/相同历史记录下，测量 g_U（当前侧）、g_V（候选侧）、g_U+g_V，并比较真实14项任务总梯度加上对应权重g_V后的方向和幅度。非零g_V本身只是结构上的可能性，不是有效性或泛化保证。

## 固定范围

三折各三个实际模型状态：原seed42角色初始化、完整Q1陈旧control终点、完整Q1 fresh_memory终点，共9状态。读取源Signal和已封存终点、绑定SHA；不重训、不修改checkpoint。每个状态重放原注册20×13=260个来源batch，全部2340次；每状态覆盖全部来源记录。三模态像素SHA、索引和历史队列按原规则逐步核对。

模型参数和buffers在整个状态测量前后相同，optimizer更新0。保持train模式角色随机性，复用每个历史原B64组的冻结anchor/reference/Signal字段和角色入口RNG；历史重编码跳过分类neck，当前完整路径的BN buffer每批恢复。这里的8步年龄仅是batch视图的存储间隔，不是8次参数更新；所有历史坐标均对应当前固定参数。不得称为原训练逐位重放、中期轨迹或缓存陈旧测量。

候选规则仍为512容量、8batch recency、65batch队列预热、同记录最新视图且取原B64最后位置、排除当前记录历史副本、按真实身份确定正负。每状态194个含历史batch。当前64个anchor平均，当前peers梯度保留；不增加历史anchor、不更换margin0.3、不做scene负标签、不引入新loss或网络。所有完整来源记录合法，heldout与official图像读取0。

## 数值与工程验证

1. T0构造向量：新可微历史式与旧detach式标量和当前侧梯度相同，候选leaf梯度经可训练线性映射VJP后与直接反传一致；合法class0保留。仅synthetic proxy。
2. 预检：9状态各8个真实B64，共72batch；队列预热2batch，实际含历史5batch/状态。每状态第一处单历史组同时保留当前+历史计算图，直接参数反传与分解g_U+g_V比较，相对L2误差预先固定≤0.005（AMP FP16路径、scale256，梯度FP32累加）；原始标量须逐位相同。这个容差仅为工程数值检查，不是研究增益门。
3. 每处历史VJP还重复同图反传，报告同角色差异与重复噪声。原字段重编码的选中坐标必须逐位一致，RNG/buffers无副作用，参数.grad保持None。历史参数梯度仅对真正非零upstream的原B64组重编码；这等价省去零链式项，不是提出选择性刷新算法。
4. 预检全CPU通过才完整9×260来源测量；全矩阵、队列、身份、loss和所有计数由独立NumPy入口核查。参数梯度/状态SHA仍为运行时见证，CPU没有独立重新模型前向/反传。保存矩阵和完整每步文本，不保存巨量全参数梯度数组。

## 输出和解释

全9状态分别报告实际g_V非零/高于重复噪声覆盖、g_U与g_V余弦、合成前后Triplet及14项总梯度的夹角、范数分布、困难正负和候选贡献计数；保留零梯度/未定义余弦，不用少数非零样本代表全部范围。报告额外角色记录前向次数、显存和时间。

这项测量不能证明历史反传会改善新身份，也不能保证缺失候选梯度是失败原因。若额外贡献接近噪声或仅限少数关系，不据此启动复杂大batch方案；若覆盖充分且确实改变学习方向，才有依据另行登记“只改变历史梯度范围”的固定配对训练。当前不自动登记或启动该训练。

GradCache提供分块表示梯度再VJP的既有链式计算思想，见docs/MSVR310_MEMORY_COORDINATE_VS_GRADIENT_BOUNDARIES_2026-09-07.md；该计算本身不宣称原创。S-XBM、BroadFace、ANCE的边界见最新原文核查。当前诊断不是新颖性对照或高性能方法。
