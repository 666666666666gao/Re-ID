# V28：池化前的三角色三模态残差 Token 联合聚合

登记日期：2026-09-07。状态：IMPLEMENTED_REGISTERED_NOT_RUN。
只有一个主假设；当前没有新的 M0、Q1 或官方成绩。

## 问题与主张

V27 完整 Q1 对匹配控制的 fused 增益为 +1.338944 mAP，五项条件通过四项，
但 fused81.592361 仍低于 CNN81.662859，故原 Q1_FAIL 保持封存。
随后完成的全部来源统计扰动诊断发现，活跃输入上纯银行错误关系从控制815降至8，
而九槽位的435053次错误中434914次已经被同角色多模态组合与融合同时救回。
这不支持继续强制每个槽位独自复制正确排名，也不支持自动叠加 V26 责任损失。

候选主张 C1：在各角色的空间信息被读出头池化之前，学习一个共同检索残差，
可能比固定拼接独立角色残差更有效。当前证据没有证明该主张。
最低支持条件是新固定配对 Q1 通过全部原科学门，且全身份与错误增减分析没有遗漏。
单次成功仍只能支持这整个新增模块；容量、Token 输入相对池化输入、扫描结构的
独立贡献需主结果成立后的同参数/同预算对照，不能预先声称新颖性已经成立。

## 与已有方法的实质区别

- V9 输入为池化后的512D槽位，含正交化、门控、额外 synergy 拼接，并冻结原角色。
- V15 在 tail9/10 之间交换角色算子增量，冻结原角色，最终仍使用原固定残差银行。
- 本项使用最终相对同一冻结 reference 的768D Patch残差，不交换中间角色状态，
  不增加一份旧银行之外的检索向量；原角色继续训练，融合使用新联合银行。
- [MambaPro](https://arxiv.org/html/2412.10707v1) 的整个3N模态序列聚合是直接启发。
  已核对作者MIT仓库commit f9ee6f60e58f21f3da1c8fd0e659fcc8db9ab149：
  modeling/fusion_part/AAM.py 与 mamba.py。其默认扫描单向，本项显式双向。
  本项输入为三角色×三模态的最终残差，保留Signal前缀与独立角色读出；
  不是MambaPro完整复现，不宣称标准Mamba、残差相加或归一化是原创。

## 唯一结构干预

C/T/M、RGB/NI/TI、Patch行优先顺序固定。每模态128个Patch。
从最后一个角色算子的真实输出读取Patch，减去相同reference的Patch：
D形状B×3角色×3模态×128×768。Transformer的原独立头仍读取CLS；
联合头读取其Patch，此输入选择须如实标注。

共享 LayerNorm(768) 和 Linear(768,128)，展成B×1152×128。
一个现有 production_mamba_factory(128)：d_state16、d_conv4、expand2。
同一组Mamba参数分别执行正序与反序，反转对齐后平均：
Z = X + [M(X) + reverse(M(reverse(X)))]/2。
恢复九组，分别对128个Patch均值池化。
每角色一份128→512无bias线性投影，在该角色的三模态间共享，权重零初始化。
将投影结果加到原512D模态残差；逐槽位L2归一化，逐角色拼接归一化，
再拼接三个角色并归一化形成4608D联合银行。
原Signal3072D按原等能量规则拼接，fused仍7680D。

control不执行联合模块，但使用相同的末端槽位再次归一化。
因此初始化配对输出须逐bit相同；与旧V8仅末端重复归一化的舍入差须小于1e-5。
原独立三分支、三个纯残差及各自分类输出通过与未修改V8 forward逐bit对照。
候选联合组含其他角色信息，不能将其称为独立专家。
新的fused不再等于报告的原独立三分支相似度平均。

保持原14项损失及全部权重，不新增银行分类、Triplet、对齐、教师或路由目标。
新增模块仅从实际部署fused的原ID/Triplet收到梯度；原六组辅助头继续监督原角色。
零投影在第一步使联合模块上游梯度为零是确定的数学性质；
要求8步与100步各阶段覆盖全部训练参数，不要求第一步所有张量非零。
不得把断开计算图包装为这个例外：所有梯度必须存在且有限，后续上游必须非零。
