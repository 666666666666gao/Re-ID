## 唯一主要干预

- control：原V8三角色固定融合，采用既有V27统计扰动。
- bounded_joint：同一基座与扰动，加入V28既有1152Token/128D/共享双向单Mamba联合头；联合修正先切向投影并平滑限制相对范数，才进入实际fused表示。
- 两端沿用原七组ID/Triplet监督、完整Signal、原独立角色读出、相同初始化、采样、优化器和更新预算。候选新增413056参数/16张量，与V28联合头数量相同；几何运算新增参数0。
- V28无界模型及其Q1_FAIL0/5封存；本次是新几何约束主实验。它与control比较整个受约束联合方案，尚不是对标准MAG限幅、普通归一化或同容量头的完整机制消融。

对当前非零槽位h及联合输出c，使用实际h范数：
```
v = c - dot(c,h)/dot(h,h) * h
r = v / sqrt(1 + dot(v,v)/(b*b*dot(h,h)))
h_new = normalize(h+r)
b = 0.5
```
固定b=0.5来自先限制补充向量不超过原表示的一半这一设计选择，未按任何held-out/dev/official分数选择，不扫描倍率。
精确算术下r与h正交，||r||/||h||<0.5，cos(h,h_new)>=1/sqrt(1.25)=0.8944271909999159，转角上限26.565051177078度。
使用实际h范数是为保持零修正时原normalize(h+0)路径，避免额外一次h归一化改变初始化SHA。
几何计算及新增joint在局部FP32；原Signal/角色AMP与Mamba fast kernel不变。每次真实前向检查相对范数上限及余弦下界，绝对舍入容差2e-6；每个训练步和每个完整图库批次保存统计。

该界只保护同一次前向的当前h到h_new，不限制h在训练中变化，也不是身份信息或mAP不下降保证。大原始c可使有界映射饱和，必须查看真实梯度和检索结果，不能因数学界成立就判有效。
不加入教师/可靠关系保留、detach代理梯度、V26、Router、XBM、PCGrad、V23MLP、V24原型或V25采样。
不以标准投影、限幅、归一化、FP32或零初始化本身主张原创。近邻包括MAG的相对范数限制、nGPT的归一化方向更新；Token聚合受MambaPro启发，非完整作者复现。
