# TriFusion V10 Dual-Foundation Complement Field 实验计划

**Problem**：V8 Phase-A 已形成查询级互补，但 hard branch Oracle 仅 64.7850 mAP；Phase-B learned Router 的 OOF 优势只有 0.000314 margin，冻结 dev fused 只有 58.4050 mAP。只在现有输出之间选择或加权不足以达到 65。

## Paper Storyline

- 主文必须证明：三专家来自同一强 CLIP pretrained tail 但保持角色差异；每支通过其他两支的正交新息获得增强；三元合成生成固定分支之外的表示；同 checkpoint fused 超过 baseline、Phase-B 和全部专家。
- Appendix 仅在主结果通过后验证：去正交、去 peer relay、单轮/双轮、去 pairwise product、等维控制。
- 当前明确裁掉：Router/alpha/epoch/LR 网格、多个 seed、提前消融、official-test 调参、运行时 fallback。
- Frontier necessity：Mamba 是既有异构专家之一，不单独主张“因为使用 Mamba 就先进”；其必要性只有主门通过后的删除实验才能验证。

## V9 单一结构假设

输入为冻结 V8 的九个 `expert×modality` 残差槽和冻结 Phase-B 路由质量：

1. **两轮 receiver-specific peer relay**：对接收专家 `e`，只从另外两支 `j,k` 构造 `[h_j,h_k,h_j⊙h_k]` 消息。
2. **Orthogonal innovation injection**：从消息中减去其在接收特征 `h_e` 上的投影，再用冻结模态质量和可学习 gate 注入，避免把三支直接拉成同一方向。
3. **Triadic synthesis**：每个模态联合三个增强专家及三组 pairwise product，生成 512D 新身份残差；样本级有界 gate 将其追加到完整 Phase-B embedding。Phase-B embedding 是 V9 fused 的逐元素精确前缀。

这是一个统一的表示学习模块，不重新训练 Router，不修改专家，不扫描残差倍率。

## V10 qualification addendum — 2026-09-02 06:03 +08:00

### Problem

V9 证明在冻结 Phase-B 槽上训练一个 684 万参数的 synergy 追加头会严重身份外
过拟合。当前实现也尚未落实最初架构要求中的第二强预训练语义源：它只有
CLIP/Signal，没有 DINO。云端已存在 DINOv2 ViT-B/14 官方格式权重，固定
SHA-256 为 `0b8b82f85de91b424aded121c7e1dcc2b7bc6d0adeea651bf73a13307fad8c73`。

### Method thesis

如果冻结 DINOv2 在完全不训练的 fit-only 跨摄像头检索中，能够与冻结
Phase-B 形成可观测的正互补，那么下一主模型才构建 CLIP+DINO 对齐语义场：

1. **Dual-Foundation Complement Decomposition**：把 CLIP 的 16×8 token
   场与 DINOv2 的 18×9 token 场确定性对齐，分解共同语义与 DINO 正交新息；
2. **Role-Disjoint Collaborative Experts**：CNN 处理局部/高频新息，
   Transformer 处理双基础模型共同全局关系，Mamba 处理空间与三模态长程传播，
   并进行 typed bidirectional exchange；
3. **Identity-OOF Utility-Protected Synthesis**：新增表示必须先在 fit identities
   的身份隔离折上产生正检索效用，并由训练侧风险证据抑制有害追加；Phase-B
   保持 exact prefix，不把训练分类记忆当作晋级证据。

这三个机制目前只是条件式方法假设。V10-Q0 未通过前不实现主模型，不赋予
论文创新结论。

### V10-Q0：冻结 DINOv2 fit-only 资格门

- 数据：仅 141-fit 中具有跨摄像头正样本的 21 个身份、571 query；query 与
  gallery 使用相同冻结记录的确定性评估视图。dev access=0，official=0。
- 模型：冻结 V8 Phase-B combined checkpoint；冻结 DINOv2 ViT-B/14。
- DINO 输入：从现有 `[0.5,0.5]` 归一化还原到 `[0,1]`，改用 ImageNet
  mean/std，双线性缩放到固定 `252×126`；patch14 产生 18×9 patch 和一个 CLS，
  总 token shape 必须为 `B×163×768`。
- 权重合同：只允许删除 checkpoint 中预训练专用的 `mask_token`，然后必须
  strict load 且 all keys matched；不允许 `strict=False` 或宽松兼容层。
- DINO embedding：每模态拼接 final CLS 与 patch mean，三模态再拼接；不训练
  projection。固定融合为 `[L2(Phase-B), L2(DINO)]`，两块等能量，不扫描倍率。
- 报告：Phase-B、DINO-only、equal-block concat 的 mAP/Rank-1；query-wise AP
  winner；Phase-B/DINO hard Oracle；checkpoint/source/input/state/访问审计。
- 成功门（全部满足）：
  - DINO strict load 与 shape/state/finite 门 PASS；
  - equal-block concat mAP 至少比 Phase-B 高 `1.0`；
  - Phase-B/DINO hard Oracle 至少比最强固定输出高 `2.0 mAP`；
  - Phase-B 与 DINO 各自至少有一个独有 query AP 胜例；
  - optimizer steps=0、training=false、dev0、official0。
- 失败解释：DINO 不是当前协议下可直接利用的互补源；停止 V10，不通过训练头、
  倍率、分辨率、block、epoch 或学习率扫描挽救。

### Conditional execution after Q0

只有 Q0 全门通过，才允许 V10-Q1 公共接缝 TDD 和真实 B64/K8 capacity。
完整主训练前还必须运行三折 identity-OOF 表示效用门：每折训练身份与检索身份
严格不重叠，三个 held-out fold 的合并 fused mAP 必须严格高于 Phase-B，且
平均增益至少 `1.0 mAP`。该门失败则不访问 dev。若通过，才允许一次 seed42、
60-epoch、final-only dev；原门保持 fused≥65 且严格超过 exact Signal、
Phase-B、CNN、Transformer、Mamba。official、消融、多 seed 仍关闭。
